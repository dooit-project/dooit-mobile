# 돌아보기 여러 목표 검토 중 확인한 실행 연결

2026-11-04 · Product Design 흐름 점검 · Chrome mock Web 390×844

## 확인한 흐름

1. 게스트 mock에서 새 목표 ‘토익 900점 받기’를 만들고, 시작일 2026-11-04인 매일 반복 계획 ‘영단어 30개 외우기’를 저장했다. [계획 화면](./01-plan.png)에서 계획과 ‘매일’ 표시를 확인했다.
2. 같은 세션에서 오늘 탭으로 이동했다. [오늘 화면](./02-today.png)은 할 일이 없는 상태였고 방금 만든 반복 계획은 보이지 않았다. 약 2.5초 후 캡처했다. 새로고침 후에도 빈 오늘 화면을 보았으나, mock의 저장 지속성은 별도 조건이므로 새로고침 결과만으로 저장 오류를 단정하지 않는다.
3. 해당 행동을 오늘 화면에서 완료하지 못한 채 [돌아보기](./03-review.png)로 이동했다. 완료 기록이 없다는 빈 상태가 보였다. 완료를 시도하지 않았으므로 이것은 돌아보기에서 완료 기록이 누락됐다는 증거가 아니다.

## 코드에서 확인한 경계와 다음 작업

- 현재 오늘 목록은 `useTodayOverview`에서 일반 Task의 오늘/완료 조회를 사용한다. 목표 회차 조회를 수행하는 `useTodayGoalOccurrences`는 정의돼 있지만 현재 코드의 화면 사용처가 검색되지 않는다.
- mock 회차 저장소는 회차 목록 조회 시 연결 Task를 생성·동기화한다. 따라서 이번 mock 재현과 일치하는 원인 후보지만, 이 기록만으로 실제 서버의 동작이나 운영 환경 장애를 단정할 수 없다.
- 로드맵의 기존 미완료 항목 F3a-2는 목표 회차를 오늘의 목표 묶음과 실행·완료·휴식/취소에 연결하는 작업이다. **여러 목표의 완료 기록을 실제로 비교하기 전에 이 경로와 API 계약을 확인하고 연결하는 것이 우선**이다. 별도의 기존 D-Day와 신규 Goal, 같은 Task의 중복·완료 취소를 구분해야 한다.
- 앞선 디자인 감사는 목표에 연결되지 않은 테스트 기록 두 건만 확인했다. 여러 목표의 시각 검토는 이번에 완료하지 못했다. 새 데이터나 성과를 꾸며서 캡처하지 않는다.

## 환경과 한계

내장 브라우저 접근 호스트 장애로 사용자가 이전에 허용한 로컬 Playwright를 사용했다. 개발용 mock 게스트 계정과 390×844 Web에서 확인했으며 운영 API, 다른 계정, Android/iOS 및 실제 알림은 확인하지 않았다. 테스트 환경 데이터는 실제 사용자 기록이 아니다.
