# 첫 로그인과 세션 만료 문구 감사

Last updated: 2026-09-16

## 문제와 선택

로그인 이력이 없는 사용자가 로그인 화면에 처음 들어와도 제목이 `다시 로그인해요`로 고정되어 있어 상황과 맞지 않았다. 기존 인증 흐름은 등록 계정의 세션 만료에만 `expired=1`을 전달하므로 별도 저장값을 추가하지 않고 이 값을 제목 분기에 사용한다.

- 첫 로그인·회원가입 직후·비밀번호 변경 후: `로그인해요`
- 등록 계정의 기존 세션 만료(`expired=1`): `다시 로그인해요`
- 게스트 기간 만료는 별도 경고문이 상태를 설명하므로 기본 제목 `로그인해요`를 유지한다.

기존 화면의 작은 문구 수정으로 구조와 위계는 유지했다. 신규 화면이나 정보 구조 선택지가 없어 3개 시각안 비교는 적용하지 않았다.

## 구현 후 화면 감사

환경: Chrome, localhost:8090, mock API, 390×844. 저장소 기본 내장 브라우저 연결을 사용할 수 없어 기존에 연결된 Chrome 환경을 사용했다.

1. [첫 로그인](./01-first-login-390.png): 정상. 제목이 `로그인해요`로 표시되고 로그인, 계정 만들기와 게스트 복귀 행동이 유지된다.
2. [등록 계정 세션 만료](./02-expired-login-390.png): 정상. 제목이 `다시 로그인해요`로 표시되며 `보안을 위해 이전 로그인 세션이 종료됐어요` 경고가 함께 노출된다.

두 캡처는 이번 실행에서 새로 저장하고 직접 확인했다. 제목은 접근성 heading으로 노출되며 경고는 alert로 노출된다. 화면 구조와 입력 동작은 변경하지 않았다. 실제 Android·iOS 스크린리더와 키보드 동작은 이번 Web 감사에서 확인하지 않았다.
