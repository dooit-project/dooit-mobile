## 검토 대상과 기준

선택한 [3번 목표 묶음](../../design/soft-goal-surfaces-2026-10-21/README.md)을 기존 계획·개인 상세에 확장했다. [구현 전 검토](../../design/PLAN_DETAIL_SURFACES_2026-10-21.md)의 범위를 따른다. 새로운 내비게이션이나 기능 완료 선언이 아니다.

Product Design audit와 기존 시안 구현 검토를 이어 적용했다. 이전에 읽은 Anthropic frontend-design, Vercel React Native/Web Interface Guidelines를 재사용했다. Figma 미사용, 새 스킬·의존성 미설치. Chrome은 이전 작업에서 내장 브라우저가 제공되지 않았던 연결을 유지한 것으로 별도 Playwright로 전환하지 않았다.

이번 작업에서 캡처를 저장하고 직접 확인했다. 새 Goal 두 개/반복 두 개의 기존 게스트 mock 세션과 D-Day/Task의 별도 데모 mock 세션을 사용했다. 둘을 같은 사용자 데이터처럼 합치지 않는다. 브라우저 콘솔 error 0.

## 시각 검토

- 타이포: 공통 본문/보조 크기는 유지. 상세 제목의 과한 heavy를 semibold로, 계획 제목은 22/30으로 정리했다. 긴 제목·설명 줄바꿈을 320에서 확인했다.
- 간격: radius 18의 흰 묶음, padding 16, 회색 바탕. 카드 안에 편집 폼의 테두리를 중첩하지 않았다. 값 없는 정보의 공간을 제거했다.
- 색: 기존 3번의 groupedBackground/surface/중립 글자/파란 활성 행동을 재사용했다. 새 색 체계를 만들지 않았다.
- 이미지/아이콘: 새로운 raster·수제 아이콘을 추가하지 않았다. 기존 표준 아이콘과 글자를 유지했다.
- 내용: 실제 값과 오류/상태만 보여준다. D-Day는 기존 목표 연결로 구분하고 존재하지 않는 D-Day 탭 안내를 제거했다. 새 Goal 연결은 여전히 후속이다.

## 잔여와 검증

- 이번 범위는 시각 정리와 날짜 상태 표시에 국한된다. 새 Goal 회차·일회성 목록·상세 연결·완료 유지/취소·여정은 미연결 상태를 유지한다.
- 전체 목표 선택의 중복 본문·선택 상태 접근성, 긴 반복 폼·오류 복귀는 후속이다. 실제로 검증한 흐름과 구분한다.
- 네트워크 실패/부분 성공·복구, Workspace 화면/권한은 이번 감사 대상 밖이다. grouped props 기본값을 꺼서 Workspace 기존 표현을 보존했다.
- `npm run validate`: 전체 통과. TypeScript/lint/format/docs/release static 검사, 112 suites / 584 tests 통과, STG integration 1개 제외. 낮은 위험의 스타일 조건을 복제하는 새 테스트는 추가하지 않았다.
- 전체 선택 시안의 1:1 구현 통과를 선언하지 않는다. 현재 변경의 근거는 선택 디자인 규칙과 이 실제 화면 감사다.
