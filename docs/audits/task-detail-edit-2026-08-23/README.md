# Task 상세 수정 행동 재점검

- 일자: 2026-08-23
- 범위: Task 상세 헤더의 `수정` 행동 위계
- 화면: [현재 Task 상세](./01-task-detail.png)

## 판정

위치는 적절하지만 현재 표현은 개선이 필요하다.

기존 검토의 핵심은 `수정`을 Task 종류 metadata와 분리해 페이지 수준 행동으로 옮기는 것이었다. 현재 구현은 그 위치 결정을 따르지만, 채워진 `secondary` 배경과 44px 버튼 면적 때문에 보조 행동이 제목과 콘텐츠보다 강하게 보인다.

## 발견 사항

1. `수정`은 페이지 헤더 우측에 있어 상세 전체를 편집한다는 범위는 명확하다.
2. 연한 회색 배경, 큰 모서리 반경, icon+label의 조합이 독립 CTA처럼 보여 실제 중요도보다 시각적 무게가 크다.
3. 헤더 제목은 28px line-height인데 버튼은 최소 44px라 헤더의 세로 균형도 버튼 쪽으로 기운다.
4. 접근성상 44px hit target과 `할 일 수정` label은 유지할 가치가 있다. 시각 크기를 줄이기 위해 실제 hit target까지 줄이면 안 된다.

## 권장안

- 헤더 위치와 icon+label은 유지한다.
- 채운 `secondary` 대신 배경 없는 `ghost` 표현으로 바꾼다.
- 실제 hit target은 44px로 유지하고, 보이는 요소는 16px icon과 label만 남긴다.
- pressed·keyboard focus 상태에서만 surface 또는 focus border가 나타나게 한다.

이 변경은 정보 구조를 다시 바꾸는 redesign이 아니라, 이미 정한 페이지 수준 행동의 시각적 위계를 바로잡는 조정이다.
