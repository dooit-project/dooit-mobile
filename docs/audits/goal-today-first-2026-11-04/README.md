# 반복 계획의 오늘 연결: 첫 단계 점검

2026-11-04 · Android/iOS/Web 공통 코드 · mock Web 점검

기준은 [사용자가 선택한 오늘 화면](../../design/goal-lanes-correction-2026-10-21/reference.png)이다. 흰 배경, 목표 색상 레일, 체크 행, 하단 탭과 공통 행 컴포넌트를 유지하고 새 화면이나 카드 구조를 추가하지 않았다. 기존 목표 묶음에 회차로 생성된 Task를 표시하는 범위다.

내장 브라우저와 Chrome 확장의 접근 호스트를 사용할 수 없어 사용자가 허용한 로컬 Playwright와 headless Chrome으로 확인했다. 게스트 mock에서 목표와 매일 반복 계획을 만들고 [계획](./01-plan.png) → [오늘](./today-390.png) → [완료](./03-done.png) → [돌아보기](./04-review.png) → [완료 취소](./05-reopen.png)를 조작했다. 목표 색이 계획과 오늘에 일치하는 것도 확인했다. 실제 화면이며 생성 시안이 아니다.

[320](./today-320.png), [390](./today-390.png), [430](./today-430.png)의 새 DOM 보고서에 `npm run check:ui-layout -- docs/audits/goal-today-first-2026-11-04/layout-320.json docs/audits/goal-today-first-2026-11-04/layout-390.json docs/audits/goal-today-first-2026-11-04/layout-430.json`을 실행해 각각 1행/2조작 영역 통과했다. 표시된 체크와 제목의 시각적 정렬도 캡처로 확인했다. 표식 없는 요소와 실제 기기 전체를 검사했다는 뜻은 아니다.

## 남은 기능과 주의점

- mock이 연결 Task 제목을 다음 행동 또는 최소 행동으로 생성하므로, 기본 행동 30개와 최소 행동 3개를 설정한 예에서 오늘은 **3개**가 표시된다. 현재 체크는 Task 완료 경로이며 회차 수준은 UNKNOWN이다. 30개를 수행했다고 추정하거나 표시하지 않는다. 기본/최소 행동의 명시적 선택, 휴식 및 각각의 취소는 미구현이다.
- 돌아보기에는 완료 Task가 보이지만 새 Goal의 이름 아래가 아니라 ‘일상의 기록’으로 표시된다. 목표별 여정과 여러 목표의 주간 기록은 아직 확인·구현되지 않았다.
- 연결 Task가 없는 회차, 독립 반복 계획, 실패·409 충돌·경쟁 상태와 재조회, 실제 운영 API를 검증하지 않았다. Android/iOS 실기기, 폰트 확대, 화면 읽기와 키보드 조작도 미확인이다. 이 결과는 F3a-2 전체 완료 판정이 아니다.
