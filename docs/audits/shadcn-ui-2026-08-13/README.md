# shadcn/ui 참고 UI/UX 점검

- 점검일: 2026-08-13
- 대상: ToDoLab Web mock 390×844
- 흐름: 시작 → Today → Calendar → Profile → Settings
- 비교 기준: [shadcn/ui](https://ui.shadcn.com/)의 Empty, Item, Card, Field, Alert, Tabs 구성 원칙

## 결론

ToDoLab의 색상과 모바일 탐색 구조는 유지한다. shadcn/ui의 Web 구현을 직접 가져오지 않고, 역할이 분명한 작은 컴포넌트와 일관된 상태 조합 원칙만 React Native 디자인 시스템에 적용한다.

우선순위는 다음과 같다.

1. 빈 상태를 icon·title·description·primary action·secondary action 구조로 통일한다.
2. Calendar, Completed, 하루 정리의 빈 상태에서 다음 행동을 제공한다.
3. Profile 메뉴를 계정·작업 도구·앱 설정 그룹으로 재구성하고 탭 이름을 역할에 맞춘다.
4. 설정과 메뉴의 반복 행을 공통 Item 계열 컴포넌트로 정리한다.
5. 시작·인증·도움말·설정 문구의 길이와 줄바꿈을 모바일 읽기 흐름에 맞춘다.

## 줄바꿈 점검

### 확인된 문제

- 시작 화면의 긴 설명은 390px에서 마지막 줄에 `있어요` 같은 짧은 서술어가 남는다.
- 본문 문장이 JSX 소스 줄에 맞춰 나뉘어 있어 편집 시 의도된 개행과 코드 포맷 줄바꿈을 혼동하기 쉽다.
- 시작·로그인·회원가입·비밀번호 재설정 제목은 강제 개행을 사용하므로 좁은 화면과 큰 글자에서 3줄 이상으로 다시 깨질 위험이 있다.
- 카드와 도움말 설명은 한 문장에 조건·행동·결과가 함께 들어가 2~3줄을 넘어가는 경우가 있다.
- 일부 목록 제목과 설명은 `numberOfLines`로 제한되어 큰 글자에서 중요한 내용이 말줄임될 수 있다.

### 적용 기준

- 본문은 강제 개행 대신 짧은 문장과 자연스러운 자동 개행을 사용한다.
- 제목의 강제 개행은 의미 단위가 유지되고 320px·font scale 1.5에서 잘리지 않을 때만 허용한다.
- 한 문장에 한 가지 정보만 담고 본문 마지막 줄에 한두 어절만 남지 않도록 문구를 먼저 줄인다.
- 중요 안내·오류·행동 결과에는 `numberOfLines`를 사용하지 않는다.
- 320px·390px·430px, font scale 1.0·1.5에서 한국어 조사·서술어와 영문 제품 용어의 줄 경계를 확인한다.

## 구현 단위

1. `EmptyState` 구조와 Today·Calendar 적용
2. Completed·하루 정리·검색 상태 행동 정리
3. 시작·인증·도움말·설정 문구와 줄바꿈 정리
4. Profile 그룹형 메뉴와 탭 명칭 정리
5. 공통 Item·Field 구성과 말줄임 정책 정리

각 항목은 별도 커밋으로 구현하고 `npm run validate`와 Web 320px·390px·430px 캡처를 함께 확인한다.

## 검증 한계

- Web mock 캡처를 기준으로 했으며 네이티브 글꼴 렌더링 차이는 포함하지 않는다.
- 스크린샷만으로 VoiceOver·TalkBack 읽기 순서, 실제 터치 영역, font scale 1.5 결과를 확정할 수 없다.
- shadcn/ui는 Web 컴포넌트이므로 패키지나 DOM 구현을 React Native에 직접 도입하지 않는다.
