# 미저장 확인 문구 점검

2026-10-29 · 기준 commit `6b5fc84` · Chrome 확장, 로컬 mock Web/light

- 대상: 할 일 수정 후 닫을 때 나오는 기존 중앙 확인. [사용자 선택 원본](../../design/discard-confirmation-2026-10-25/01-centered-decision.png)의 구조·버튼 순서·얇은 경계는 유지한다. 저장하지 않음의 결과를 분명히 알리면서 부담스러운 어조를 줄인다.
- Product Design audit와 저장소 기존 [외부 기준 검토](../discard-confirmation-2026-10-26/README.md)를 적용했다. 공식 접근성 자료를 이전 기록으로 재사용했으며 새 경쟁 앱 직접 사용이나 외부 전문가 인증은 아니다.
- [변경 전](./01-before.png): ‘버리기’가 제목과 빨간 버튼에 반복되어 취소 상황보다 강한 경고로 보인다. [변경 후](./02-after-390.png): ‘저장하지 않고 나갈까요?’, ‘지금까지 입력한 내용은 저장되지 않아요.’, ‘저장하지 않기’와 ‘계속 작성’으로 수정하고 보조 글자를 중립색으로 바꿨다.
- 실제 흐름: 수정한 제목에서 취소하면 확인창이 보인다. 계속 작성 시 제목이 유지되고, 저장하지 않기를 선택하면 원래 제목의 상세로 돌아간다. 두 행동은 다른 문구와 색으로 구분되고 초기 초점은 계속 작성이다.
- [320](./02-after-320.png)·[390](./02-after-390.png)·[430](./02-after-430.png) ×844 실제 캡처와 좌표를 확인했다. 상단 1행 정렬 및 확인창 2버튼의 44px 조작 영역이 모두 통과했다. Android/iOS 실기기, 스크린 리더, 확대, 운영 API와 다른 미저장 진입 경로의 실제 조작은 미확인이다.
