# 일반 할 일·일정의 긴 제목

2026-10-29 · 기준 `16ecc44` 이후 작업 트리 · Chrome 확장, 로컬 mock Web/light

- 범위: 기존 일반 TaskCard/ScheduleCard의 제목을 두 줄로 자르지 않고 줄바꿈한다. 오늘의 목표별 행과 달력 격자, 보조 설명·메타 정보, 카드 구조·완료 동작은 유지한다. [선택한 오늘 시안](../../design/goal-lanes-correction-2026-10-21/reference.png)과 [긴 이름 판단](../long-goal-labels-2026-10-24/README.md)을 따른다.
- 사전 검토: 기존 Product Design의 긴 목표 이름 검토에서 Todoist·Things 공식 자료를 참고한 판단을 재사용했다. 목록의 실행 내용은 전체를 읽게 하며 좁은 달력 격자는 압축 표현을 유지한다. 이번에 경쟁 앱을 직접 조작한 것은 아니다.
- [기존 320 일정 목록](./01-before-320.png)은 두 줄 제한 상태이나 이후 스트레스 제목과 원문이 달라 같은 데이터의 전후 비교는 아니다. [한글·영문 혼합 일정](./02-schedule-320.png)은 자연스럽게 보인다. [320 최대 길이 스트레스](./04-task-320.png)는 연속 영문 30자로 일정과 할 일 각각 세 줄을 확인한 인공 데이터다. [390](./05-task-390.png)·[430](./05-task-430.png)도 직접 확인했다.
- 할 일 제목·완료 버튼·상세 진입, 일정 제목과 시각 정보가 서로 겹치지 않는다. 320/390/430의 긴 할 일 실제 좌표는 각 1행/2조작 영역 통과다. 일정은 캡처의 광학적 검토 범위이며 별도 좌표 검사는 하지 않았다. mock 제목은 원상 복원했다.
- Android/iOS 실기기, 글자 확대, 완료 상태의 긴 제목과 Workspace·검색 등 다른 호출 경로의 실제 화면은 미확인이다. 해당 컴포넌트를 사용하는 Android/iOS/Web 화면에 영향이 있다.
