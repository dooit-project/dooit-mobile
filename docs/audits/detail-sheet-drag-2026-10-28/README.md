# 상세 시트 손잡이 동작 감사

2026-10-28 · R5 · 기존 선택 시안의 손잡이 동작 보완

- 기준: 사용자가 선택한 [상세 시안](../../design/task-detail-options-2026-10-24/05-context-panel-aligned.png)과 [이전 실제 전체 수정 화면](../task-schedule-edit-2026-10-27/12-shared-full-editor-390.jpg). 새 화면 구조는 만들지 않았다. 기존 공통 시트의 손잡이 그림과 총 상단 높이를 유지했다. 시안과 실제는 예시 데이터와 상태가 달라 손잡이와 패널의 구조만 비교한다.
- 사전 검토: 기존 Product Design 감사의 [외부 기준 검토](../task-form-external-recheck-2026-10-26/README.md)를 재사용했다. 새 경쟁 앱 직접 조작이나 외부 전문가 인증은 아니다. 손잡이 드래그는 보조 닫기이며 기존 닫기 버튼과 저장되지 않은 변경 확인을 유지한다.
- 실제 검증: Chrome 확장, 로컬 mock Web/light. 데스크톱에서 손잡이를 충분히 당기면 닫히고 원래 할 일로 초점이 돌아왔다. 짧게 당기면 열린 상태로 복귀한다. 수정한 제목이 있을 때 데스크톱과 390×844에서 당기면 [기존 확인창](./02-dirty-mobile.png)이 열리고 계속 작성 시 입력이 유지된다. 최초에는 드래그 중 주변 글자가 선택되어 이를 수정하고 다시 확인했다.
- 320/390/430×844에서 편집 화면을 [캡처](./screen-390.png)하고 실제 좌표를 수집했다. 각각 4행/14조작 영역 기하 검사 통과. [상세 390 화면](./03-detail-390.png)은 시각 참고이며 예시 데이터가 원본과 다르다. 모양·글꼴·아이콘·문구의 의도적 변경은 없다.
- `npm run validate`: 129 suites/693 tests 통과, opt-in STG 1개 제외. 변경 범위는 Android/iOS/Web 공통이다. 실제 Android/iOS 터치, 스크린 리더, 확대, 짧은 높이, 메뉴 열림·저장 중 및 운영 API는 확인하지 않았다. 드래그 하나에 의존하지 않고 닫기 버튼을 유지한다.
