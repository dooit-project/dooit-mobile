# Today 완료 영역 표시 조건

## 구현 전 검토

- 기준: `40e88fb` 이후 작업 트리. Android·iOS·Web 공통 Today 화면.
- 문제: 완료 항목이 없어도 제목과 0개가 남아 화면에 불필요한 영역을 만든다.
- 선택: 사용자 요청대로 `doneTasks.length > 0`일 때만 제목·개수·목록 전체를 렌더링한다. 기존 미리보기·전체 보기·다시 열기 동작을 유지한다.
- 작은 조건 변경으로 신규 정보 구조 선택이 없으므로 3안 비교는 생략한다.
- 확인할 상태: 완료 0개, 1개, 마지막 항목 다시 열기 후 0개.

## 검증 환경

- API: mock, localhost:8090
- 내장 브라우저가 `Browser is not available: iab`로 실패했다. 복구 지침과 브라우저 목록 확인 결과 Chrome 확장만 연결돼 있어 Chrome으로 전환했다.
