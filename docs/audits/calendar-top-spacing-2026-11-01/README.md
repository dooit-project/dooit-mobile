# 달력 상단 여백 보정

2026-11-01 · 미커밋 작업 트리 · Product Design 검토

- 범위: 사용자가 선택한 [달력 보정 시안](../../design/calendar-navigation-2026-10-30/04-refined.png)과 월 제목 중앙 정렬, 오늘 버튼을 유지한다. 달력 본문의 상단 간격만 16px에서 8px로 줄이고 공통 헤더나 다른 탭의 간격은 변경하지 않았다.
- [변경 전](./01-before-390.jpg)과 [변경 후](./02-after-390.jpg)는 같은 Chrome 반응형 Web 390×844의 mock 빈 날짜 화면이다. 포인터·날짜 초점 상태에는 차이가 있다. [표시용 화면](./05-display.jpg)은 변경 후 실제 캡처에서 브라우저 주변을 잘라낸 것이다.
- [320px](./03-after-320.jpg), [430px](./04-after-430.jpg)에서도 제목과 버튼의 배치를 육안으로 확인했다. 다음 달 이동과 오늘 복귀를 조작했다. 6주 달의 빈 날짜 상태를 확인한 것이며 데이터가 있는 모든 상태에 대한 검증은 아니다.
- 기존 [오늘 버튼 검토](../calendar-today-button-2026-10-31/README.md)의 Android 접근성 안내와 Google Calendar의 오늘 복귀 패턴을 참고했다. 이번 범위에서 외부 앱을 새로 조작한 것은 아니다.
- 내장 브라우저와 Chrome 확장의 접근 호스트 장애로 Chrome 앱과 DevTools 반응형 모드를 사용했다. 새 DOM 좌표 보고서와 `check:ui-layout`은 미완료다. 글자 확대, 키보드 초점, 스크린 리더, Android/iOS 실기기와 운영 데이터도 미확인이다. 최종 시각 QA는 pending이다.

캡처 자료에서 개인 브라우저 탭 정보가 포함된 상단 영역은 제거했다. 문서의 원본 캡처 링크는 이 정보가 제거된 기록이며, 잘리지 않은 파일은 로컬 임시 보관소에 보존했다.
