# Drawer 아이콘과 글자 중심 확인

2026-10-23 · `20b9211` 이후 공통 아이콘 working tree · 구현 변경 없음

- 대상/목적: 사용자가 지적한 메뉴 아이콘과 글자의 세로 중심을 확인한다. 기존 메뉴 구조와 간격은 유지한다.
- 도구: Product Design index/audit 기준, CUA Chrome 확장. IAB가 inventory에 없어 기존 localhost:8082 tab을 유지했다. 390×844, Web light, mock 화면이다.
- 근거: 이번에 저장하고 직접 연 [실제 화면](./01-before.jpg), `planner-drawer.tsx`와 `AppIcon`의 현재 구현. 기존 공통 아이콘 감사의 참고 기준을 재사용했다. 외부 앱·Figma를 새로 검증한 것은 아니다.
- 측정: 검색은 아이콘 wrapper와 글자 모두 y=84, 높이 24로 중심이 같다. 다른 한 줄 메뉴도 24 높이의 같은 중심을 공유한다. Feather 내부 glyph는 22px, line-height normal로 높이 24.5이다. 레이아웃 박스 정렬과 실제 획의 시각 중심은 다를 수 있다.
- 판단: 박스 가운데 정렬은 적용돼 있지만 그림과 한글의 실제 획 여백까지 맞췄다고 할 수 없다. 일부 아이콘이 높게 느껴지는 지적은 시각 보정 대상으로 남긴다. 모든 아이콘에 임의의 전역 offset을 적용하지 않는다.
- 카테고리: 아이콘은 제목과 보조 문구의 합계 44 높이 블록 중앙에 놓인다. 제목 한 줄 중앙과는 다른 기준이다.
- 경계: 확인은 Web 기본 글자 크기의 메뉴에 한정한다. native, 글자 확대, dark, 스크린리더는 미확인이다. 코드 변경이 없어 이번에는 validate를 반복하지 않았다. 새 UI 구현 완료 판정이 아니다.

1. 메뉴 열기: 정상. 버튼 이름과 구조 유지.
2. 한 줄 메뉴 중심 비교: 박스 중심 일치. 시각 중심 보정 검토 필요.
3. 두 줄 카테고리 비교: 블록 중심 정렬이며 제목 기준 정렬 여부는 후속 판단.
