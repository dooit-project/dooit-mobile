# Workspace 접근 오류 UI/UX 점검

- 점검일: 2026-08-19
- 대상: Dooit Web mock 390×844
- 흐름: 존재하지 않는 Workspace 직접 접근 → 상태 이해 → 공유 공간 목록 복귀

## 결론

404 상태를 기술 오류 대신 삭제·탈퇴 가능성으로 설명하고, 다시 시도보다 목록 복귀를 우선 행동으로 제공한다. 제목, 원인, 행동이 한 경고 영역에 담겨 첫 화면에서 모두 확인된다.

## 확인 한계

- mock 404 화면을 확인했으며 실제 백엔드의 PENDING·REMOVED·비멤버 응답 조합은 실행 환경에서 별도 검증해야 한다.
- 스크린샷만으로 screen reader의 alert 낭독 순서와 키보드 포커스 이동을 확정할 수 없다.
