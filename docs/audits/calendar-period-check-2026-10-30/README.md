# 여러 날 일정 상세 표시 검토

2026-10-30 · 기준 `1349b4e` 이후 작업 트리 · Product Design 검토

- 사용자 목적: 달력에서 기간 일정을 찾고 상세에서도 시작·종료를 올바르게 읽는다. 기존 [선택 상세 시안](../../design/task-detail-options-2026-10-24/05-context-panel-aligned.png)의 정보 행·아이콘·편집 진입은 유지한다. [기존 Google Calendar 공식 안내 검토](../calendar-review-2026-10-30/README.md)는 참고 자료이며, 다른 앱 직접 조작은 아니다.
- 브라우저 확장 연결이 중단되어 Chrome 앱의 접근성 조작으로 전환했다. 로컬 mock 기본 계정의 예시 데이터로 [달력 기간 막대](./01-desktop.png)를 직접 확인했고 시작일을 선택하면 해당 날짜 목록에도 표시됐다. 막대를 눌러 상세를 열었다. 이 화면은 desktop 크기이며 모바일 시뮬레이션이 아니다.
- [수정 전](./02-detail-before.png): 10월 29일 09:00부터 31일 18:00까지의 일정이 29일 09:00–18:00으로 표시되어 종료 날짜를 숨겼다. [수정 후](./03-detail-after.png): 시작과 종료 날짜·시각이 함께 표시된다. 같은 날 일정은 기존 시간 범위를 유지한다. 여러 날 종일 일정의 배타적 종료 자정은 마지막 점유 날짜로 바꿔 보여준다. 저장 데이터는 변경하지 않는다.
- 세부 동작: 달력 막대에서 상세 열기와 해당 예시 일정의 실제 Web 표시를 확인했다. 같은 날·여러 날·연도 경계·자정·종일·미지정은 자동 테스트 범위다. 실제 종일/연도 경계 화면과 운영 API, 화면 읽기, Android/iOS 실기기 및 작은 화면은 미확인이다.
- 현재 Chrome 확장/내장 브라우저의 접근 호스트 연결 실패로 새 DOM 좌표 측정을 수행할 수 없었다. 따라서 저장소 `check:ui-layout`의 이번 변경 통과를 주장하지 않는다. 실제 화면 전체의 icon 광학 정렬도 desktop만 확인했다. 연결 복구 후 320/390/430의 긴 날짜 줄바꿈·아이콘 중심·44px 조작 영역을 측정해야 한다.
