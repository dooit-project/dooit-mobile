# Workspace 반복 범위 UI/UX 점검

- 점검일: 2026-08-18
- 대상: Dooit Web mock 390×844
- 흐름: 반복 일정 제목 수정 → 수정 범위 확인 → 삭제 범위 변경

## 결론

반복 일정에서만 범위 선택을 노출하고 기본값을 `이번만`으로 두어 의도하지 않은 일괄 변경을 줄였다. 세 범위는 한 줄에서 비교할 수 있고, 선택 결과를 바로 아래의 짧은 설명으로 확인할 수 있다.

## 단계별 결과

| 단계 | 화면                               | 상태 | 판단                                                                                                      |
| ---- | ---------------------------------- | ---- | --------------------------------------------------------------------------------------------------------- |
| 1    | [수정 범위](./01-edit-scope.jpg)   | 양호 | 제목 입력 다음에 범위가 이어져 저장 전에 적용 대상을 확인할 수 있고, 390px에서 버튼 문구가 잘리지 않는다. |
| 2    | [삭제 범위](./02-delete-scope.jpg) | 양호 | 위험 영역 안에서 삭제 대상과 범위를 함께 보여 주며 `전체` 선택 시 과거 일정 포함 여부를 명시한다.         |

## 확인한 기준

- 수정·삭제 진입 때마다 안전한 기본값인 `이번만`으로 초기화한다.
- 선택된 범위는 색상과 `selected` 접근성 상태를 함께 사용한다.
- `이후 모두`와 `전체`의 차이를 선택 직후 설명 문구로 안내한다.
- 일반 일정에는 범위 선택을 노출하지 않는다.

## 확인 한계

- Web mock 390px 캡처를 기준으로 했으며 iOS·Android 글꼴 렌더링 차이는 포함하지 않는다.
- 스크린샷만으로 VoiceOver·TalkBack의 선택 상태 낭독과 글자 크기 확대 결과를 확정할 수 없다.
