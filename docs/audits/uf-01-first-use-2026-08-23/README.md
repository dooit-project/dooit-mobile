## 판정

정상 경로와 입력 오류는 현재 mock에서 연결된다. 다음 예외·복구 상태는 추가 검증이 필요하다.

- 로그인 화면에 비밀번호 재설정 진입점이 없어 `/password-reset` 직접 경로로만 확인했다. 백엔드 준비 전 의도적으로 숨기는 정책인지, 안내 화면으로 연결할지 제품 결정을 맞춰야 한다.
- 게스트 생성 loading이 즉시 끝나 캡처할 수 없다. 실제 API 지연, timeout, 생성 실패와 재시도 상태가 필요하다.
- 계정 연결의 실제 데이터 병합 성공·실패, 401 세션 만료, 새로고침과 앱 재실행 뒤 session 복원은 mock 캡처 범위 밖이다.

FigJam 보드는 흐름도, 위 10개 최신 화면, 검토 이슈 영역으로 구성했다. 구현 기준은 이 저장소의 [`USER_FLOW_CATALOG.md`](../../product/USER_FLOW_CATALOG.md)로 유지한다.
