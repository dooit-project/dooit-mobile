# 현재 UI P1 재점검

- 점검일: 2026-08-20
- 대상: ToDoLab Web mock 390×844
- 범위: Task 상세 정보 밀도, 설정 카드·행 일관성
- 사용자 목표: 상세 화면에서 중요한 일정과 다음 행동을 빠르게 찾기

## 결론

설정은 카드마다 제목·설명·상태 또는 행동이 일관되어 별도 공통 Item 추상화가 필요하지 않았다. Task 상세은 일정과 관리 기록이 한 카드에 같은 무게로 이어지는 문제가 확인되어, 기본 일정 정보만 유지하고 미룸·이월 기록은 값이 있을 때만 별도 그룹으로 표시하도록 개선했다.

## 적용 결정

- 일정·반복·계획일·목표일·종일·카테고리는 `일정 정보`에 유지한다.
- D-Day 상태는 바로 아래 관리 행동에서 한 번만 표시한다.
- 미룬 이유와 이월 횟수는 실제 값이 있을 때 `관리 기록` 그룹으로 표시한다.
- 설정·메뉴의 공통 Item 추가는 현재 화면의 일관성을 높이지 않으므로 진행하지 않는다.

## 확인 한계

- Web mock의 한 Task와 development 설정 상태를 기준으로 확인했다.
- 긴 설명, 반복 Task, 완료·미룸 이력이 모두 있는 상세 화면은 별도 데이터 회귀가 필요하다.
- VoiceOver·TalkBack, font scale 1.5와 네이티브 터치 영역은 실제 기기에서 확인해야 한다.
