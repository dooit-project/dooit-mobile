# Workspace 상세 정보 구조 UI/UX 점검

- 점검일: 2026-08-18
- 대상: ToDoLab Web mock 390×844
- 사용자 목표: 공유 일정, D-Day, 멤버 관리 중 현재 작업 하나에 집중하기

## 결론

기존 한 페이지 구성은 일정 편집 아래에 D-Day와 멤버가 계속 이어져 현재 작업과 무관한 정보까지 읽게 했다. 상세 본문을 세 탭으로 분리한 뒤 첫 화면 높이와 행동 수가 줄었고, 각 탭에서 관련 생성 행동만 보이게 됐다.

## 개선 근거

- Workspace 이름과 내 권한은 공통 맥락이므로 탭 위에 유지했다.
- 일정 탭을 기본값으로 두고 D-Day와 멤버 관리는 한 번의 명시적 선택 뒤 노출한다.
- 탭은 44px 이상의 높이와 `tab`·`selected` 접근성 상태를 사용한다.
- 선택 탭은 색상과 외곽선을 함께 사용해 색상만으로 상태를 전달하지 않는다.

## 확인 한계

- 빈 상태 중심의 Web mock 캡처이며 여러 일정·목표·멤버가 쌓인 스크롤 상태는 별도 확인이 필요하다.
- 키보드 방향키 탭 이동, VoiceOver·TalkBack 읽기 순서, 글자 크기 확대는 스크린샷만으로 확정할 수 없다.
