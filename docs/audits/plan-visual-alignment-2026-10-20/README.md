## 근거와 구현 전 판단

선택된 [최종 생성 시안](../../design/plan-navigation-2026-10-15/05-goal-tabs-polished.png)을 직접 열고 기존 실제 캡처와 비교했다. 기존 시안의 국소 보정이므로 신규 방향 세 개를 다시 만들지 않는다. Product Design index·image-to-code·audit와 저장소 정책을 적용했고 user-context preflight에는 저장 컨텍스트가 없었다. 앞선 세션에서 내장 브라우저가 제공되지 않아 Chrome으로 전환한 사유를 유지했다. 이번 Chrome 연결 시간초과는 같은 탭을 reload해 복구했다. Figma와 운영 앱 조작은 하지 않았다. 기존 시안 문서의 공식 Material 목록/탭·Things/Todoist 자료 판단을 재사용했다.

계획은 목표 아래 반복 정의·항목을 관리하고 오늘은 날짜별 실행을 담당한다. 탐색 위치는 유지한다. 시안 해상도를 모바일 크기로 환산해 파란 브랜드/선택, 남색 보조 정보, 선형 아이콘, 제목·본문·요일의 위계를 복원한다. 생성 이미지의 과도한 상단 공백은 기존 사용자 결정대로 제외한다. 의미 없는 카드·구분선은 추가하지 않는다.

## 실제 확인 단계

1. 변경 전 — [00-before](./00-before.png). 실제 빈 계획 화면의 검정 로고·회색 탭·작은 본문을 확인했다. 항목이 있는 변경 전 상태는 이전 감사의 캡처를 참고 자료로만 사용했다.
2. 계획 — [02-plan-two-goals](./02-plan-two-goals.png). UI에서 목표 두 개·선택 목표일·반복 두 개를 생성하고 목표 전환을 확인했다. 파란 로고/선택선·목표색 점·보조 정보·배경 없는 관리 메뉴·왼쪽 추가 행을 확인했다. 목록 행과 추가의 선형 아이콘을 맞췄다. [01-plan](./01-plan.png)은 아이콘 최종 보정 전 중간 상태다.
3. 작은/큰 화면 — [03-plan-320](./03-plan-320.png), [04-plan-430](./04-plan-430.png). 전체 목표 버튼을 고정하고 목표 탭만 가로 스크롤한다. 320에서는 다음 탭 일부가 보이고 현재 탭과 전체 목표는 유지된다. 이것은 목표 제목을 임의 축약하는 방식이 아니다.
4. 영문 문구 — [05-long-quote-320](./05-long-quote-320.png). 수동 교체로 짧은 Emerson 인용과 긴 Keller 인용을 확인했다. 긴 문장은 두 줄로 들어가고 저자 줄/교체 아이콘이 없다. 버튼의 접근성 이름에는 전체 문장이 있다.
5. 다른 페이지 — [06-today](./06-today.png), [07-calendar](./07-calendar.png), [08-review](./08-review.png), [09-drawer](./09-drawer.png). 공통 로고·글자·색·탭과 메뉴 진입을 확인했다. 달력 아래 추가 버튼은 스크롤 영역에 있으며 이번 작업이 달력 구조를 재설계한 것은 아니다. 08의 좌하단 번개 표시는 개발 서버 UI이며 제품 구성으로 평가하지 않았다.
6. 출처 — [10-quote-sources](./10-quote-sources.png). 설정에서 실제 영문과 출처 목록을 펼쳤다. 링크를 외부로 열지는 않았다. 노출 설정과 문장 교체 동작은 유지한다.

각 캡처를 저장한 뒤 직접 열어 확인했다. 생성 시안을 실제 화면 증거로 사용하지 않았다. 자동 검증 결과는 아래에 기록한다.

## 시안과의 남은 차이·한계

시안에는 일정·일회성 할 일을 포함한 네 항목이 있지만 실제 새 Goal 화면에는 두 반복 정의만 있다. 지원하지 않는 Goal별 일회성 조회를 시각 데모로 위장하지 않았다. G-07 계약 확인 후 혼합 목록과 단일 ‘항목 추가’를 연결해야 한다. 현재 ‘반복 계획 추가’라는 정확한 이름을 유지한다. API의 목록 순서도 시안 예시와 다르며 수동 순서 계약은 별도다.

시안과 동일한 네 항목·동일 순서 비교는 완료하지 못했다. 목표 이름도 자동 축약하지 않으므로 시안의 짧은 탭 텍스트와 다르다. 큰 이미지의 여백을 복사하지 않고 헤더 52·목표 탭 48·본문 20 간격으로 구현했다. 로고는 기존 텍스트 표현을 유지해 생성 이미지 글자 형태와 완전히 같지는 않다.

일반 본문 16/24, 보조 13/18, label 14/20과 파란 primary/남색 textSecondary는 공통 적용이다. 본문·탭·아이콘을 일괄 확대하지 않았다. light/dark 대비는 자동 검사 대상이며 실제 dark 화면은 미확인이다. 공통 변경의 영향 플랫폼은 Android/iOS/Web이고 실제 화면 감사는 Web에 한정한다. native safe area·키보드·VoiceOver/TalkBack·글자 확대 1.5·전 화면의 모든 상태는 미확인이다.

남은 접근성 후속: 기존 비활성 탭 콘텐츠가 DOM snapshot에 남는 현상의 실제 보조 기술 노출, 상태 변경 후 초점 복귀. 이번 변경으로 완료했다고 표시하지 않는다. 신규 의존성·API 변경은 없다.
