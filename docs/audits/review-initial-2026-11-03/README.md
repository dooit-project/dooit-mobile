# 돌아보기 주간 탐색 초기 확인

2026-11-03 · 로컬 Playwright / Chrome mock Web 390×844

1. [이번 주 빈 상태](./01-current.png): 범위와 빈 기록 안내, 오늘으로 가기 동작이 보인다. 현재 주에서 다음 주·이번 주는 비활성이다.
2. [이전 주 빈 상태](./02-previous.png): 이전 주 이동 뒤 범위와 문구가 바뀌고 이번 주 버튼이 활성화된다. 이번 주 버튼을 눌러 현재 주 범위로 돌아오는 것을 확인했다.

달력의 월 탐색과 비교하면 범위가 화면 중심보다 왼쪽에 있고, 좌우 이동 화살표도 제목에서 멀리 떨어져 있다. 이번 주 조작은 텍스트만 보여 달력의 테두리 버튼과 표현이 다르다. 두 화면이 같은 역할의 탐색을 제공하므로 일관성 보정을 다음 작업 후보로 삼는다. 현재는 기존 화면 캡처와 탐색 확인이며 새 시안 또는 수정 후 결과가 아니다.

완료 기록이 있는 상태, 긴 기간 표현, 320/430, 키보드·스크린 리더 및 Android/iOS·운영 API는 확인하지 않았다. 화면 구조나 기능 변경의 타당성을 결정하기 전에 기록이 있는 상태도 살펴볼 필요가 있다.
