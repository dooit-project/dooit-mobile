## 판정

Task 생성, 상세 조회, 수정 진입·취소, 삭제 확인·취소, 영구 삭제와 Today 복귀의 정상 경로는 연결된다.

1. 빈 제목에서는 저장 버튼이 비활성이라 잘못된 제출을 예방하지만, 카탈로그에 적힌 별도 validation 메시지 상태는 현재 존재하지 않는다. 버튼 비활성만 유지할지 입력 안내를 추가할지 기준을 맞춰야 한다.
2. 삭제 확인은 상세 화면 하단의 inline 영역으로 나타난다. 위험 행동을 의도적으로 아래에 두는 장점은 있지만 390×844에서도 확인 문구와 버튼을 함께 보려면 하단 스크롤이 필요하다.
3. 수정 취소와 삭제 취소는 원래 상세로 돌아오며 값이 유지됐다. 영구 삭제 뒤에는 Today로 복귀하고 삭제한 Task가 목록에 남지 않았다.

## 아직 확인하지 못한 상태

- 날짜 빠른 변경 네 가지와 실패 rollback
- 긴 제목·설명, 일정·종일·날짜 없음 조합
- D-Day 연결·해제
