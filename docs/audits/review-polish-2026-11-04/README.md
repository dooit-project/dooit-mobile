# 돌아보기 시각 위계 재검토

2026-11-04 · Product Design audit 기준 · 로컬 Playwright / Chrome mock Web

## 범위

- 대상: 주간 탐색과 완료 기록의 시각 위계. 기존 목표별 기록과 주 이동, 데이터 의미 및 하단 탭을 유지한다.
- 비교 기준: [같은 기록이 있는 이전 화면](./before-populated-390.png)과 [변경 후](./after-populated-390.png). 두 화면은 390×844, 같은 테스트 일정 1건이다. 현재 주의 주간 범위를 더 읽기 쉽게 하고, 비활성 이번 주 버튼은 불필요한 테두리를 보이지 않는다. 기록 영역 제목은 내용과 연관된 제목으로 분명하게 드러낸다.
- [지난 주 빈 상태 390](./after-previous-390.png)에서는 돌아갈 수 있는 이번 주 버튼을 외곽선으로 표현한다. 클릭 후 다시 현재 주와 완료 기록이 보이는 흐름을 확인했다. 캡처의 이전 화살표 테두리는 클릭 후 포커스 표시다.
- [320](./after-previous-320.png), [430](./after-previous-430.png)에서 같은 빈 상태를 확인했다. 좁은 화면에서는 날짜가 잘리지 않도록 기존 작은 날짜 크기를 유지한다. 아이콘과 날짜의 배치 및 화면 가로 넘침을 캡처에서 확인했다.
- 새 DOM 기하 검사: [320](./after-layout-320.json), [390](./after-layout-390.json), [430](./after-layout-430.json), 각 1행 / 4조작 통과. 실제 폰트의 보이는 중심과 색 대비, native 접근성까지 보장하지 않는다.

## 참고와 한계

- [Todoist 완료 기록 안내](https://www.todoist.com/help/todoist/get-started/get-started-with-todoist-OgNNJR)는 완료한 일을 다시 살펴보는 흐름을 설명한다. [Apple Health의 요약·상세 안내](https://support.apple.com/en-sa/guide/iphone/iphe3d379c32/27/ios/27)는 기간별 정보와 상세 탐색을 설명한다. 공식 안내를 참고한 것이며 외부 앱을 직접 사용하거나 외부 전문가 승인을 받은 것은 아니다.
- 내장 브라우저 접근 호스트가 없어 사용자가 이전에 승인한 로컬 Playwright를 사용했다. 사용자 조사, 여러 목표·다수 기록, 연도 경계, 실제 스크린 리더·글자 확대, Android/iOS 실기기와 운영 API는 미확인이다. 텍스트 위계 보정은 기존 선택 구조 안에서 진행했으며 더 큰 정보 구조 변경은 별도 비교가 필요하다.
