## 구현 결과

기본 폼에서 알림7/반복5/단위3의 동시 노출을 없애고 **현재 값 두 행**을 항상 보여준다. 유형의 기존 단일3분할은 유지한다. 추가 정보는 설명/예상 시간/카테고리만 포함하며, 초기 알림/반복 유무만으로 펼치지 않는다.

알림을 누르면 해당7개(종일은2개)만, 반복을 누르면 해당5개만 plain text 선택 행으로 보여준다. 현재 값은 파란 글자·체크·접근성 설명으로 표시한다. 서로 전환하는 action 목록이므로 radio 방향키 선택을 즉시 실행시키지 않고 button/Tab/Enter/Space를 사용한다. 선택 즉시 부모 초안으로 돌아오며 Task 저장은 하지 않는다.

직접 반복은 간격과 현재 단위 행·요약·적용만 보여준다. 단위를 누를 때만 일/주/개월 목록을 연다. 유효한1–99만 적용하고, 오류는 간격 바로 아래·invalid 경계·입력 초점으로 전달한다. 잘못된 간격의 반복 요약은 표시하지 않는다. 뒤로 가면 적용하지 않은 값을 버리고 이전 설정을 유지한다. 현재 설정 닫기/Back/Escape는 자식 단계부터 돌아간다. 부모 초안이 있으면 최종 닫기에는 기존 중앙 버리기 확인을 유지한다.

TaskForm의 기본 입력은 mount를 유지하고 숨김/보조 기술 제외를 함께 적용한다. 부모의 ScrollView ref를 공통 Screen/DetailSheet에서 전달하며, 복원은 React commit 이후 layout effect에서 수행한다. Web은 preventScroll focus 복귀, native는 기존 접근성 초점 함수를 사용한다. 새 작성/기존 상세가 같은 hook을 공유한다. 이전 미커밋 ChoiceChips 실험은 새 구조에서 쓰지 않으므로 제거하고 기존 SegmentedControl을 유지했다.
