# 돌아보기 주간 범위 한 줄 보정

2026-11-04 · 로컬 Playwright / Chrome mock Web

- 범위: 사용자의 두 줄 표시 피드백에 따라 주간 범위를 한 줄로 표시한다. 기존 돌아보기 기록, 현재 주 상태, 주 이동과 최소 44 조작 영역은 유지한다.
- [320 지난주](./after-previous-320.png)는 `10.26 – 11.1`로 시작과 끝을 구분하고 한 줄로 표시한다. [390 현재 주](./after-populated-390.png)는 기존 날짜 표기를 유지한다. [320 연도 경계](./after-year-320.png)는 `25.12.29–26.1.4`로 축약하며, 화면 읽기 이름은 기존처럼 완전한 연·월·일 범위를 제공한다. 두 자리 연도와 구분자에 공백이 없는 점은 좁은 화면의 가독성 한계다.
- 테스트 일정의 완료 기록이 있는 주에서 지난주로 이동한 뒤 이번 주로 돌아오는 동작을 320/390/430에서 확인했다. 캡처 속 이전 화살표 테두리는 조작 후 초점 표시이며, 일부 320 캡처의 검은 번개는 Expo 개발 오버레이다.
- [320](./after-layout-320.json), [390](./after-layout-390.json), [430](./after-layout-430.json), [연도 경계 320](./after-year-layout-320.json)의 DOM 기하 검사에서 각각 1행 / 4조작 통과했다. 실제 Android/iOS, 글자 확대, 스크린 리더 음성 및 운영 API는 미확인이다.
- 내장 브라우저 접근 호스트 장애로 앞서 사용자가 승인한 로컬 Playwright를 사용했다. [이전 두 줄 실제 화면](../review-clarity-2026-11-04/after-previous-320.png)과 비교했다.
