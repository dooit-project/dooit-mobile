- 이번 변경: 조사 결과와 실제 현황을 기록한다. 앱 코드·API·저장 계약은 변경하지 않는다. 다음은 설계 추천이며 새로운 구조의 사용자 선택이나 구현 완료를 뜻하지 않는다.

## 추천 표시 규칙

1. **목표 탭:** 현재 한 줄 + 끝 말줄임 + 가로 스크롤을 유지한다. 선택 탭 자동 노출과 전체 접근성 이름을 보존한다. 글자를 줄여 끼워 넣거나 자동으로 흘러가는 글자를 만들지 않는다.
2. **선택 목표 제목/전체 목표 목록:** 고정 두 줄 말줄임 대신 필요한 만큼 자연스럽게 줄바꿈한다. 모바일의 hover나 길게 누르기만으로 전체 이름을 확인하게 하지 않는다. 앞부분이 같은 목표도 전체 목표에서 구별할 수 있어야 한다.
3. **실행 항목의 제목:** 탭 라벨과 구분한다. 무엇을 해야 하는지 읽는 본문이므로 줄바꿈으로 내용을 보존하고 세부 설명은 상세에 둔다. 이번에는 Today/상세의 모든 긴 제목을 새로 감사하지 않았다.
4. **넓은 화면의 탭 폭:** 현재 172 제한 때문에 430에서도 탭 이름이 더 길게 보이지 않을 수 있음을 명시한다. 이를 오류로 단정하지 않는다. 향후 폭을 조정한다면 실제 탐색 표시 폭 안에서 한 탭이 전체를 독점하는 비용/이웃 목표 발견 가능성과 함께 320/360/390/430에서 비교한다. 이번에는 수치를 임의 변경하지 않는다.

두 줄 탭은 긴 이름 몇 개 때문에 탭 바가 높아지고 목표마다 밀도가 달라져 현재 선택안에는 권하지 않는다. 별도 짧은 이름 입력은 관리 부담을 늘리고 목표 이름과 탐색 이름을 불일치시킬 수 있어 추가하지 않는다. 목표 수가 많아지는 문제는 기존 전체 목표/검색으로 다루며 새 dropdown으로 바꾸지 않는다.
