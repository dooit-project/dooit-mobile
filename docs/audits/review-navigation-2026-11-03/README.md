# 돌아보기 주간 탐색 보정

2026-11-03 · Product Design 기준 검토 · 로컬 Playwright / Chrome mock Web

- 범위: 주간 범위·이전/다음·이번 주의 배치를 달력 탐색에 맞춘다. 돌아보기 기록, 빈 상태, 주 이동과 탭 구조는 유지한다. 기준은 [기존 돌아보기 실제 화면](../review-initial-2026-11-03/README.md)과 [달력 월 탐색](../calendar-recheck-2026-11-03/02-populated.png)이다.
- 완료 기록 1개가 있는 동일 상태의 [이전](./before-populated-390.png)과 [변경 후](./populated-390.png)를 비교했다. 범위를 화면 가운데에 두고 화살표를 범위 가까이 놓았으며 이번 주 조작은 달력처럼 작은 외곽선을 사용한다.
- [이전 주 320](./previous-320.png), [390](./previous-390.png), [430](./previous-430.png)에서 이전 주 이동·이번 주 복귀를 확인했다. 320에서 처음 날짜가 줄바꿈되어 좁은 폭의 날짜 크기와 양쪽 공간을 보정했다. 캡처상 아이콘·문구 중심을 확인했다.
- 새 DOM 좌표 검사: 각 1행·4조작 통과. [320](./layout-320.json), [390](./layout-390.json), [430](./layout-430.json). 기하 검사는 native 접근성이나 글리프의 광학 정렬을 보장하지 않는다.
- 브라우저 접근 호스트 문제로 앞서 허용된 로컬 Playwright를 사용했다. 새해를 넘는 긴 주간 범위, 글자 확대, 실제 키보드·스크린 리더, Android/iOS와 운영 API는 확인하지 않았다. 테스트 기록은 mock 데이터다.
