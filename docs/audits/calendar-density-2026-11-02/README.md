# 달력 상단 간격 단계별 보정

2026-11-02 · [기준 시안](../../design/calendar-navigation-2026-10-30/04-refined.png)과 [직전 검토](../calendar-spacing-recheck-2026-11-02/README.md)를 유지하는 국소 보정

- 같은 390×844 mock Web에서 [기존](./01-before.jpg), [1차](./02-first.jpg), [2차](./03-second.jpg), [더 조밀한 3차](./04-third.jpg)를 확인했다. 최종은 세 번째보다 버튼 안쪽 여유와 선택기·오류 간격을 더 둔 [결과](./05-final-390.jpg)다. [앱 영역 표시용](./08-display.jpg)은 실제 결과의 바깥 브라우저를 자른 것이다.
- 월 제목·화살표·오늘 버튼의 보이는 내용을 터치 영역 안에서 위로 조정하고 월 조작 행 아래 패딩을 제거했다. 44/48 조작 영역은 코드상 유지하고 행을 겹치지 않는다. 글자 확대 시 보정 패딩을 빼고 제목 높이가 커질 수 있도록 했다. 확대 글자는 실기기에서 검증하지 않았다.
- [320](./06-final-320.jpg), [430](./07-final-430.jpg) Web 화면을 육안 확인하고 390에서 월 선택·12월 이동·오늘 복귀를 조작했다. 빈 mock 데이터와 기본 글자 조건이다. 첫 이용 안내·실제 데이터·키보드 및 화면 읽기 음성은 확인하지 않았다.
- 내장 브라우저와 Chrome 확장 접근 호스트 장애로 Chrome 앱의 DevTools 반응형 모드를 사용했다. 실제 DOM 좌표 수집과 `check:ui-layout`은 미완료다. Android·iOS 실기기와 실제 터치는 미확인이다. 기하 검사와 native 확인 전 시각 QA는 pending이다.

캡처 자료에서 개인 브라우저 탭 정보가 포함된 상단 영역은 제거했다. 문서의 원본 캡처 링크는 이 정보가 제거된 기록이며, 잘리지 않은 파일은 로컬 임시 보관소에 보존했다.
