## 판정

Calendar 날짜 탐색, 검색 결과·빈 상태·상세 왕복 복원, 완료 기록의 날짜 탐색과 다시 열기까지 정상 경로는 연결된다.

1. Calendar는 단일 일정과 여러 날 일정을 월 그리드에서 구분하고, 선택 날짜 아래에 예정·완료 목록을 제공한다. 빈 날짜에는 설명과 `이 날짜에 일정 추가` CTA가 나타난다.
2. 검색에서 `백엔드` 결과 두 건을 확인했고 상세를 열었다 돌아와도 검색어와 결과가 유지됐다. 결과가 없을 때는 조건 초기화를 제공한다.
3. 일정 검색 결과의 날짜 출처·Task 유형·카테고리가 모두 `일정`일 때 같은 라벨이 반복되던 문제를 수정했다. 같은 메타데이터 라벨은 한 번만 표시한다.
4. 완료 기록에서 한 건을 다시 열자 선택 날짜와 주간 집계가 2개에서 1개로 즉시 갱신됐다. 같은 SPA 세션에서 Today 목록 반영까지 이어지는 캡처는 남아 있다.

## 아직 확인하지 못한 상태

- Calendar 월 선택, 이전·다음 주, 겹치는 여러 날 일정과 `+N` overflow
- 검색 상세 필터, 정렬, cursor 다음 페이지와 network·timeout 오류
- 완료 기록 이전·다음 주, 여러 개 더 보기, 다시 열기 실패와 Today 반영
- 새로고침 뒤 검색 조건 복원 여부
- keyboard 전체 순서, zoom 150%, font scale, VoiceOver·TalkBack
