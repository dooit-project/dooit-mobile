# 돌아보기 이번 주 버튼과 빈 상태 위치

2026-11-04 · Product Design 검토 기준 · 로컬 Playwright / Chrome mock Web

- 범위: 사용자가 승인한 동일한 ‘이번 주’ 버튼과 빈 상태 위치를 보정한다. 날짜 탐색, 기록 목록·상세 및 하단 탭은 유지한다. 비교 기준은 [기존 빈 주](../review-week-button-2026-11-04/previous-390.png)와 [기록 두 건](../review-refine-2026-11-04/after-populated-390.png)이다.
- [현재 주 390](./current-390-844.png)은 테두리 버튼을 연하게 비활성 표시하고, [지난주 390](./previous-390-844.png)은 같은 위치의 버튼이 활성화된다. 320·390·430 및 [320×568](./previous-320-568.png)에서도 지난주 이동과 이번 주 복귀를 확인했다. ‘오늘로 가기’로 오늘 경로에 이동하는 것도 확인했다. 지난주 캡처의 이전 화살표 테두리는 클릭 후 초점 표시다.
- 빈 주의 안내는 상단 탐색과 하단 탭 사이의 남은 본문 영역 가운데에 배치한다. 안내가 차지할 공간이 부족하면 스크롤로 늘어날 수 있도록 고정 높이를 지정하지 않았다. [기록 두 건 390](./check-populated-390.png)은 기존 위쪽 목록 위치를 유지하며, 기록 상세를 열고 닫는 흐름도 확인했다.
- 빈 주의 320/390/430과 320×568은 각 1행 / 4조작, 기록이 있는 320/390/430은 각 3행 / 5조작, 320 연도 경계는 1행 / 4조작 DOM 기하 검사를 통과했다. 수치 검사는 광학적 정렬이나 native 접근성을 보장하지 않는다.
- [Carbon 빈 상태 가이드](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)의 빈 공간 내 중앙 배치와 [Atlassian 빈 상태 문구 안내](https://atlassian.design/content/designing-messages/empty-state/)를 참고했다. 외부 서비스 앱 직접 조작은 아니다.
- 내장 브라우저와 native 앱 접근 호스트 장애로 사용자에게 이전에 승인받은 로컬 Playwright를 사용했다. 데이터는 목표 미연결 테스트 완료 기록 두 건이다. 글자 확대, 여러 목표, 실제 스크린 리더, Android/iOS 실기기와 운영 API는 미확인이다. 일부 캡처의 검은 번개는 Expo 개발 오버레이다.
