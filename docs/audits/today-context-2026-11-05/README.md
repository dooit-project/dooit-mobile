# 오늘의 반복 행동 맥락 보정

2026-11-05 · 기준 커밋 `1c637b5` 이후 작업 · Android/iOS/Web 공통 · mock Web 점검

## 범위와 원본

- 원본: [사용자가 선택한 오늘 시안](../../design/goal-lanes-correction-2026-10-21/reference.png). 흰 배경·목표 레일·체크·하단 추가·네 탭을 유지한다.
- 기존 [실제 390×844 화면](../today-sparse-review-2026-11-04/02-today.png)과 같은 목표 1개·매일 계획 1개를 만든 [수정 후 실제 화면](./02-today.png)을 비교했다. 헤더 문구는 순환하므로 같지 않다. 생성 시안의 두 목표·다섯 항목과는 데이터가 다르다.
- 변경: 공통 ItemCopy의 보조 행에 확인 가능한 반복 요일·시작 조건과 연결 Task가 실제 최소 행동인 경우 ‘작은 행동’을 표시한다. 다음 행동이 있거나 기본과 최소가 같은 경우 작은 행동이라고 단정하지 않는다. 일치하는 계획 버전이 없으면 요일을 생략한다.
- 기존 하단 추가 버튼의 위치는 유지했다. 목록이 적은 경우의 빈 공간은 남으며 목록 끝으로 옮기는 대안은 긴 목록·키보드·작은 화면에서 비교가 더 필요하다.

## 점검 결과

Product Design audit 기준으로 실제 캡처의 정보 위계·행 정렬·상태를 검토했다. [Things의 오늘 목록](https://culturedcode.com/things/support/articles/4001304/)과 [Todoist의 오늘 화면](https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs) 공식 안내는 실행할 항목을 모으고 프로젝트 기준 그룹을 제공한다. 이 비교는 공개 안내 확인이며 앱을 직접 조작하거나 동일 화면을 시각 비교한 결과가 아니다. 목표별 목록과 직접 체크를 유지하는 설계 판단에만 참고했다.

게스트 mock에서 목표·반복 계획 작성 → 오늘 표시 → 체크 → 돌아보기 → 체크 취소를 확인했다. 현재 회차 체크는 UNKNOWN이며 돌아보기는 새 Goal 아래 귀속되지 않는다. 기본/최소 행동을 선택해 실제 수행한 수준으로 기록하는 기능과 여정 연계는 미구현이다. 연결 Task의 제목만 바꿔 실제 한 일을 추정하지 않는다.

내장 브라우저/Chrome 확장 접근 호스트 장애로 사용자가 승인한 로컬 Playwright/headless Chrome을 사용했다. [320](./layout-320.json)·[390](./layout-390.json)·[430](./layout-430.json)의 새 DOM 검사 각 1행/2조작 영역 통과, [390 캡처](./02-today.png)에서 체크와 첫 줄의 시각적 정렬을 확인했다. 버튼·보조 글자의 실제 기기 접근성, 장문·글자 확대·스크린 리더·Android/iOS와 운영 API는 미확인이다.
