# Dooit 기존 화면 전체 감사

Last updated: 2026-08-31

## 환경과 범위

- 플랫폼: Expo Web static export
- API mode: mock guest
- viewport: 390×844
- theme: light
- 캡처: 첫 진입, Today, Calendar, 더보기, 오늘 계획, 하루 마감, Task 작성·상세, 검색, 완료 기록, 목표, Task 템플릿, 공유 공간, 설정, 로그인, 회원가입, 비밀번호 재설정
- 동적 Workspace 상세는 guest 계정에 참여 Workspace가 없어 제외했다.

## 총평

Dooit의 슬로건인 “생각난 일은 가볍게 기록하고, 오늘 해야 할 일은 선명하게.”는 `빠른 기록 → Today → 오늘 계획 → 하루 마감 → 완료 기록` 흐름으로 제품에 반영되어 있다. 특히 Today의 단일 primary action, 기록함 저장과 날짜 빠른 변경, 계획·마감의 빈 상태는 기능을 과장하지 않고 다음 행동을 설명한다.

다만 기능이 늘면서 `더보기`가 목적지 목록 역할을 떠안고 있었고, 이번 drawer가 이를 완화한다. 다음 우선순위는 새 기능 추가보다 drawer smart 진입, 브랜드 표현 통일과 실제 기기 접근성 검증이다.

## 화면별 판정

1. **첫 진입 — 양호:** 게스트 시작과 로그인 선택이 분리되어 있다. 게스트 복구 불가 안내는 길지만 위험을 숨기지 않는다.
2. **Today — 양호:** 주간 strip, 오늘 할 일, 완료 목록과 빠른 기록 순서가 슬로건에 맞다. 새 공통 header로 menu 발견성이 생겼다.
3. **Calendar — 보통:** 월·날짜·목록 위계는 명확하나 390px Web에서 세로 scroll bar와 하단 내용이 동시에 보여 다소 답답하다.
4. **더보기 — 보통:** 계정과 도구가 이해되지만 drawer와 목적지가 중복된다. 전환 검증 후 축소 대상이다.
5. **오늘 계획 — 양호:** 빈 상태에서도 완료 행동이 명확하다. 기록함·지난 미완료 direct focus는 아직 없다.
6. **하루 마감 — 양호:** 부담 없는 설명과 Today 복귀가 선명하다. 실제 다중 항목·부분 실패 캡처는 추가로 필요하다.
7. **Task 작성 — 양호:** 제목과 유형이 먼저 보이고 세부 정보는 접혀 있다. disabled 저장 상태도 구분된다.
8. **검색 — 보통:** filter가 촘촘하지만 검색어, 상태, 상세 filter, 결과 위계는 유지된다. font scale 1.5 점검이 필요하다.
9. **완료 기록 — 양호:** 기간 이동, 일별 수와 빈 상태가 한 맥락에 있다.
10. **목표 — 보통:** 설명은 명확하지만 빈 화면의 여백이 커 첫 목표 action이 상단에만 의존한다.
11. **Task 템플릿 — 보통:** 설명과 새 템플릿 action은 명확하다. 빈 상태에서 예시 없이 기능 가치를 상상해야 한다.
12. **공유 공간 — 양호:** guest 제한과 로그인 action이 같은 notice에 있어 복구 가능하다.
13. **설정 — 양호:** 알림 권한 제약과 사용 가이드가 과도한 설정 없이 정리되어 있다.
14. **인증 3종 — 양호:** 제목, 설명, form과 보조 action 순서가 일관된다. 원형 `D` 표시는 앱 icon과 통일할 여지가 있다.
15. **Task 상세 — 양호:** 상태, 빠른 날짜 변경과 일정 정보가 읽기 순서대로 배치된다. 긴 화면의 삭제 action까지 scroll 확인이 필요하다.

## 우선순위 발견 사항

- **P1 없음:** 확인한 빈 상태와 핵심 이동에서 사용을 막는 문제는 없었다.
- **P2:** drawer `기록함`·`오래 미룬 일` smart 진입 분리.
- **P2:** 320px, font scale 1.5, dark, VoiceOver·TalkBack, Android와 iOS 실제 기기 검증.
- **P2:** 다중 데이터가 있는 오늘 계획·하루 마감·Calendar·Workspace 상세 상태 추가 감사.
- **P3:** 인증 화면의 `D` placeholder를 현재 Dooit brand asset과 통일.
- **P3:** drawer 안정화 후 하단 `더보기`와 Profile 목적지 중복 축소 검토.

## 한계

- Web mock의 light·empty 중심 감사다. Native gesture, keyboard, safe area, large text와 screen reader 결과를 대신하지 않는다.
- Workspace 상세, error/loading, 긴 목록과 실제 알림 권한 prompt는 이번 데이터에서 재현하지 않았다.
- 캡처는 감사 근거이며 대표 store screenshot을 자동으로 대체하지 않는다.
