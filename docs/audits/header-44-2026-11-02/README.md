# 공통 헤더 44 높이 보정

2026-11-02 · 선택된 달력 구조의 작은 간격 보정

- [사전 Product Design 검토](../calendar-spacing-recheck-2026-11-02/README.md)의 제안대로 공통 헤더의 최소 높이를 48에서 44로 줄였다. 메뉴의 44 조작 영역, safe area, 월 제목 가운데 정렬, 오늘 버튼과 네 탭은 유지한다. 긴 문구나 확대 글자로 콘텐츠가 커지면 최소 높이보다 늘어날 수 있다.
- 같은 mock Web 390×844의 [전](./07-before-display.jpg)과 [후](./06-display.jpg)를 비교했다. 표시용 이미지는 각 원본 [전](./01-before.jpg)과 [후](./02-after-390.jpg)의 앱 부분이다. 시각적 차이는 작다. 메뉴·로고·문구와 월 제목의 정렬은 유지되어 보인다.
- [320](./03-320.jpg)·[430](./05-430.jpg) 달력과 [320의 두 줄 영문 문구](./04-320-long.jpg)를 육안으로 확인했다. 430에서 오늘·계획의 빈 상태도 확인했다. 돌아보기와 데이터가 있는 화면, 첫 이용 안내는 이번에 확인하지 않았다.
- 내장 브라우저 및 Chrome 확장 접근 호스트 장애로 Chrome 앱과 DevTools의 반응형 mock Web을 사용했다. DOM 보고서는 수집하지 못해 `check:ui-layout`은 실행하지 못했다. Android/iOS 실기기, 확대 글자, 실제 터치와 스크린 리더는 미확인이다. 화면 품질 최종 확인은 pending이다.

캡처 자료에서 개인 브라우저 탭 정보가 포함된 상단 영역은 제거했다. 문서의 원본 캡처 링크는 이 정보가 제거된 기록이며, 잘리지 않은 파일은 로컬 임시 보관소에 보존했다.
