# 상단 동기부여 문구와 출처

작성: 2026-10-16 · 설정/영속 이력까지 `b1915a1`에 코드 반영, 미검증

## 제품 기준

사용자가 선택한 위치는 dooit 로고 옆의 작은 문구다. 큰 카드·자동 팝업·실천 완료 때마다 바뀌는 문장을 추가하지 않는다. 사용자의 바람을 존중하고 시작하기 쉬운 행동·실천 기록·다시 돌아오기를 이야기한다. 휴식이나 빠진 날을 실패로 취급하지 않으며 기록 없는 성과·노력·감정을 단정하지 않는다.

## 콘텐츠 원본

[문구 목록](../../src/features/motivation/motivational-lines.ts)에 자체 문장 13개와 출처 확인 명언 2개를 둔다. 자체 문장은 인물 이름을 붙이지 않는다. 명언 항목은 저자·원문 발췌·출처 URL·위치·확인일을 필수로 가진다. 한국어는 원문 일부의 짧은 직접 의역이며 현대 한국어 번역을 복사한 문장이 아니다. UI에서도 저자와 `의역`을 표시한다.

| ID                | 확인한 자료                                                                                                                                  | 위치·표현 범위                                            |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `laozi-step`      | [도덕경, James Legge 번역 원문](https://www.gutenberg.org/files/216/216-h/216-h.htm)                                                         | 64장 2절의 여정과 첫걸음 구절. 2026-10-16 직접 확인       |
| `keller-optimism` | [American Foundation for the Blind의 원문·작품 안내](https://www.afb.org/about-afb/history/helen-keller/quotes/helen-keller-quotes-optimism) | 1903년 Optimism 인용의 첫 문장 일부. 2026-10-16 직접 확인 |

온라인에서 인물 이름만 붙여 퍼지는 출처 미확인 문장은 넣지 않는다. 사용자가 예로 제시한 `내일은 그냥 오지 않는다`는 인용 출처를 확인하지 않았으므로 유명인 명언이나 dooit 자체 창작으로 편입하지 않았다. 새 인물 문구를 추가할 때도 출처·원문 위치·번역 범위를 함께 기록한다.

## 교체 동작

- 첫 노출은 기기의 현지 날짜에 따라 정한 문장을 사용한다.
- 새 날 또는 마지막 교체 후 4시간이 지난 상태에서 앱/브라우저로 복귀하거나 경로를 이동하면 다음 문장으로 바꾼다.
- 화면을 계속 보고 있을 때는 타이머로 바꾸지 않는다. 재렌더와 완료 체크만으로 교체하지 않는다.
- 문구 옆 작은 교체 아이콘과 전체 44 이상 터치 영역을 제공한다. 누르면 다른 문장을 볼 수 있다.
- 같은 헤더가 유지되는 동안 최근 7개를 피한다. 단순히 문구를 바꾸기 위해 서버나 AI를 호출하지 않는다.
- 긴 문장은 한 줄로 말줄임하며 접근성 이름에는 전체 문장을 제공한다. 인물 문구에는 저자와 의역 여부도 읽어준다.

초기 문구/순환 단계는 `b174172`로 커밋했다. 이어서 아래의 노출 설정·영속 이력·원문 출처 UI를 후속 코드에 반영했다. 실제 기록 기반 주간 피드백이나 반복 실천 기능의 구현을 대신하지 않는다.

## 노출 설정과 이력 저장 — 2026-10-16 후속

설정 화면의 기존 outlined Card/라디오 선택 패턴을 사용한다. 별도 설정 화면·팝업은 추가하지 않으며 설정 화면의 항목 증가에 맞춰 스크롤을 활성화했다.

| 선택    | 동작                                                                 |
| ------- | -------------------------------------------------------------------- |
| 기본    | 새날/마지막 교체 후 4시간이 지난 재방문에 자동 교체                  |
| 덜 보기 | 자동 교체를 하루 한 번으로 제한. 문구를 직접 누르는 수동 교체는 허용 |
| 숨기기  | 상단 문구와 교체 버튼을 표시하지 않음                                |

`덜 보기`는 문구가 하루 중 한 번만 나타났다가 사라지는 동작이 아니라 **자동 교체 빈도**를 줄이는 선택이다. UI 설명에도 이를 명시한다. 읽는 도중 타이머로 교체하지 않는 원칙은 유지한다.

- 저장: 서버 사용자 ID·API 모드/주소별로 모드·현재 문구 ID·노출 시각·현지 날짜·최근 7개 문구 ID를 이 기기에 저장한다. Android·iOS는 기존 SecureStore, Web은 localStorage를 사용한다. 계정이 달라지면 다른 범위의 저장값을 읽으며 계정 간 기기 동기화는 아니다.
- 복원: 헤더 재마운트와 앱 재시작 후에도 저장된 이력으로 이어간다. 문구 순서의 배열 인덱스 대신 안정적인 문구 ID를 저장하고, 삭제된/잘못된 ID는 정리한다. 숨김 설정을 읽기 전에 기본 문장을 먼저 노출하지 않는다.
- 동기 반영: 설정과 헤더는 같은 구독 저장소를 사용한다. 설정 저장 성공 후 선택 상태와 헤더를 갱신하며 여러 쓰기는 순차 처리한다. 설정 저장 실패 시 기존 모드를 유지하고 재선택을 안내한다.
- 오류 복구: 읽기 실패 시 문구를 노출하지 않고 설정에서 재시도할 수 있다. 문구 이력의 쓰기 실패는 현재 세션에서 문구 교체를 막지 않으며 설정에서 저장 실패를 알린다. 다음 교체 때 다시 저장한다. 이력 쓰기 실패 상태에서는 재시작 후 최신 이력을 복원한다고 보장하지 않는다.
- 출처: `명언과 출처 보기`를 펼치면 두 인물 문구의 전체 문장·저자·의역 여부·원문 위치를 표시한다. 사용자가 `원문 출처 열기`를 눌렀을 때만 외부 링크를 연다. 링크 열기 실패는 같은 맥락에서 재시도를 안내한다. 기존에 확인한 출처를 재사용하며 새 인용문을 추가한 단계는 아니다.
- 접근성: 노출 선택은 라디오 그룹·선택/비활성 상태와 설명을 제공한다. 로딩 중에는 선택을 막고, 실패/성공 안내는 기존 InlineNotice로 표시한다. 출처는 긴 내용을 말줄임하지 않고 읽을 수 있으며 설정 전체는 세로 스크롤한다.
- 검토 범위: Product Design의 선택 존중·맥락 유지·정보 위계·복구 기준과 기존 설정 컴포넌트를 확인했다. 새로운 Figma 파일·외부 앱 조작·실제 화면 캡처 검토는 아니다. 화면을 바꾸는 큰 시각 선택 대신 기존 설정 카드/라디오/펼침 패턴을 재사용한다.
- 상태: 후속 변경은 `b1915a1`로 커밋했으며 미검증이다. Android·iOS·Web 공통이며 신규 의존성·API/백엔드 변경 없음. 사용자 요청대로 `npm run validate`와 실제 화면 감사를 보류했다. 실제 저장소·계정 전환·앱 재시작·복귀·키보드/스크린리더 동작은 아직 재현 확인하지 않았다.

다음 범위는 기록 기반 주간 회고와 사용자 선택에 따른 시스템 조정이다. 신규 Goal/반복/여정 계약이 필요한 부분은 백엔드 회신 범위를 확인한 뒤 연결한다.

## Product Design 검토 기록

- 대상/목적: 실행 화면을 밀어내지 않으면서 작은 행동과 바람을 지지하는 문장을 가끔 보여준다.
- 근거: 기존 작은 상단 헤더, 선택된 최종 시안의 문구 위치, [일상 반복 점검의 노출 제안](./DAILY_SYSTEM_FIT_REVIEW_2026-10-13.md)과 출처 원문을 확인했다. 기존 Product Design의 시각 위계·방해 최소화·발견 가능성 기준을 적용했다. 새 Figma·실제 앱 캡처 검토는 아니다.
- 유지/변경: 헤더 기본 높이 52와 한 줄 문구를 유지하고, 교체 조작과 명언 저자 한 줄을 추가한다. 명언에는 저자 줄이 있으므로 실제 좁은 화면/글자 확대에서 밀도 확인이 남아 있다.
- 접근성: 문구 교체는 버튼 역할·전체 문장·힌트·눌림 반응을 제공한다. 새 문장은 강제 live announcement로 읽는 중간에 끼어들지 않는다.
- 플랫폼: Android·iOS·Web. 기존 AppState를 사용하며 설치된 React Native Web의 visibilitychange 연결을 소스에서 확인했다. 실제 복귀·키보드·터치·스크린리더 동작을 테스트한 것은 아니다.
- 검증: 사용자 요청으로 `npm run validate`와 실제 화면 감사를 보류했다. 새 의존성·API 계약 변경은 없다.
