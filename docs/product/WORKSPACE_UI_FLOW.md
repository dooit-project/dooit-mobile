# Workspace UI 점검 흐름

Workspace 화면은 한 번에 한 가지 목적에 집중한다. 상세 화면에서 일정, D-Day, 멤버 관리를 동시에 길게 나열하지 않고 탭으로 분리한다.

## 사용자 흐름

| 진입           | 기본 화면        | 다음 행동                | 완료 확인                            |
| -------------- | ---------------- | ------------------------ | ------------------------------------ |
| 받은 초대      | 공유 공간 목록   | 초대 수락                | 참여 중인 공간으로 즉시 전환         |
| 공유 공간 선택 | 일정 탭          | 일정 조회·추가·수정·삭제 | 일정 목록에서 결과 확인              |
| D-Day 탭       | 공유 목표 목록   | 목표 추가·삭제·일정 연결 | 같은 Workspace 안에서 연결 결과 확인 |
| 멤버 탭        | ACTIVE 멤버 목록 | 초대·권한 변경·제거      | 멤버 목록과 권한에서 결과 확인       |

## 화면 구조

```text
공유 공간 목록
├─ 받은 초대
└─ 참여 중인 공간
   └─ Workspace 상세
      ├─ 권한 요약
      ├─ 일정 탭 (기본)
      ├─ D-Day 탭
      └─ 멤버 탭
```

## 점검 기준

- 첫 진입에서는 가장 자주 확인하는 오늘의 공유 일정만 표시한다.
- 탭을 바꿔도 Workspace 이름과 현재 권한 맥락은 유지한다.
- 생성·수정 폼은 관련 탭 안에서만 펼친다.
- OWNER 전용 멤버 초대는 멤버 탭에서만 노출한다.
- 빈 상태는 현재 탭의 다음 행동만 안내한다.
- 320px·390px·430px와 글자 확대에서 탭 문구가 잘리거나 두 줄이 되지 않아야 한다.

## 캡처 순서

1. 공유 공간 목록과 받은 초대
2. 일정 탭 기본 상태
3. 일정 수정·삭제 상태
4. D-Day 탭 기본·편집 상태
5. 멤버 탭 기본·초대·권한 관리 상태

각 공유 UI 변경은 위 순서에서 영향받는 화면을 캡처하고, 줄바꿈·행동 위계·선택 상태·오류 복구를 확인한다.
