# 오늘 메인 개선 작업 목록

2026-11-05 · [실제 화면 검토](../audits/today-main-design-2026-11-05/README.md)와 사용자 합의

기준은 [선택된 오늘 시안](../design/goal-lanes-correction-2026-10-21/reference.png)이다. 흰 배경·목표색 레일·원형 체크·작은 동기 문구·네 탭을 유지한다. 점수, 목표 달성률, 큰 배너와 기록에 없는 성과를 추가하지 않는다. 각 작업은 실제 화면·상태를 확인하고 결과와 미확인 환경을 남긴다.

1. [ ] **평소/작은 행동과 완료 기록.** 평소 행동과 작은 행동을 명확히 선택하고 수행한 것만 기록한다. 완료 취소, UNKNOWN 기존 기록, 중복 제출·실패·버전 충돌을 보존한다. 연결 Task와 돌아보기에서 작은 행동을 평소 행동의 결과로 오인하지 않도록 사실에 맞게 이어진다. 회차가 Task를 구체화하므로 목록 중복 및 캐시 갱신도 확인한다.
   - 진행 중: 화면에서 본 회차 버전, 명시적 선택과 실제 시각을 담는 요청 생성 및 UNKNOWN 결과의 보수적 표시 기반을 추가한다. 아직 화면에 연결하지 않았으며 체크 동작은 기존과 같다. 먼저 연결 Task 제목과 돌아보기의 기록 불일치 처리까지 함께 구현해야 한다.
2. [ ] **목표별 기록.** 새 Goal의 반복 실천·일회성 완료를 원본 기준으로 돌아보기에 연결하고 중복 집계를 막는다. 여러 목표와 날짜·빈 상태·불러오기 실패, 기존 D-Day와의 구분을 확인한다.
3. [ ] **오늘 항목의 시각 위계.** 공통 ItemCopy와 토큰을 활용해 목표 제목·행·보조 정보의 크기, 간격, 체크 중심을 보정한다. 원본과 같은 데이터·뷰포트, 짧은/긴 제목 및 상태를 비교한다.
4. [ ] **추가 버튼과 화면 밀도.** 목록 끝과 하단 고정을 동일한 짧은/긴 목록·작은 화면·키보드 조건에서 비교하고 선택된 안으로 구현한다. 자주 쓰는 추가 행동의 발견성과 접근성을 유지한다.
5. [ ] **상단 헤더.** 메뉴·로고·순환 문구의 비율과 중심선·여백·긴 문구를 공통 헤더 기준으로 다듬는다. 오늘과 다른 페이지를 함께 확인한다.
6. [ ] **빈 상태·모두 완료·휴식.** 실제 상태를 구분하고 다음 행동을 가까이 제공한다. 휴식은 실패로 표현하지 않고 모든 격려는 기록에 근거한다.
7. [ ] **목표 아래의 일회성 할 일·일정과 다음 행동.** 등록·수정·오늘·계획·달력·목표별 기록의 연결과 빠진 진입점을 먼저 조사하고 계약을 확인해 구현한다.

새 화면이나 의미 있는 정보 구조의 선택지가 생기면 실제 기준과 시각안 세 개를 비교하고 선택 후 구현한다. 각 구현은 Product Design 사전 검토, 동일 조건의 실제 캡처, 새 Web DOM 좌표 검사와 `npm run validate`를 따른다. 운영 API·Android/iOS·글자 확대·보조 기술 등 확인 범위는 구분해 기록한다.
