# 전체 UI/UX 후속 작업

2026-10-21 최초 기록 · 2026-10-22 디자인 우선순위 갱신

[10월 22일 실제 Web 재감사](../audits/visual-cohesion-2026-10-22/README.md)의 VC-01–08과 [공통 디자인 기준](../design/VISUAL_COHESION_REVIEW_2026-10-22.md)을 우선 적용한다. 현재 순서는 **공통 헤더/스타일 → 계획·상세 → 작성/편집 → 달력·돌아보기 → 보조 화면**이다. 새 목표 선택 탭 노출과 오류 필드 초점 복귀도 재현됐다. 아래 기능 의존성은 유지하며 이번 회차 앱 코드 변경은 없다.

시각 기준은 [사용자 첨부 원본의 흰 배경·색상 레일](../design/goal-lanes-correction-2026-10-21/README.md)이다. 이전 카드형 ‘3번’ 연결은 구현 측 참조 오류로 정정했다. [동일 내용 실제 비교와 보정](../audits/goal-lanes-correction-2026-10-21/README.md)은 미커밋이다. 기존 Task 완료 유지/취소, 계획·상세 빈 정보 축소와 날짜 정정을 반영했다. 새 Goal 회차/여정은 미연결이다. 시안 일부 일치와 전체 앱의 완성도는 별도로 판단한다.

근거는 [전체 감사와 수정 목록](../audits/whole-app-2026-10-21/README.md), 실제 화면은 [33개 캡처](../audits/whole-app-2026-10-21/SCREENS.md)에 둔다. 이 문서는 다음 작업의 순서와 완료 조건을 관리한다. 새로운 시안이나 기능 구현 완료 문서가 아니다.

## 유지할 방향

- 오늘 / 달력 / 계획 / 돌아보기 네 탭과 현재 순서. 더보기는 하단으로 되돌리지 않는다.
- 계획은 목표·반복 정의·연결 항목 관리, 오늘은 날짜별 실행, 달력은 날짜별 탐색, 돌아보기는 실제 기록 확인.
- 파란 브랜드/선택·선형 아이콘·작은 문구. 사용자 첨부 원본에 따라 흰 바탕에 목표별 색상 레일을 사용하고 항목별 카드는 피한다. 전역 글자 크기를 다시 일괄 조정하지 않는다.
- 목표 퍼센트·노력 점수·연속 달성 압박·큰 명언 카드·근거 없는 AI 격려는 추가하지 않는다.

## 계약이 필요한 부분

- UX-14 (2026-10-23, 중간): 로컬 mock에서 항목 제목 편집 후 Today/상세에는 새 제목, 이미 열린 계획 D-Day 목록에는 이전 제목이 남았다. [실제 검증 기록](../audits/goal-item-typography-2026-10-23/README.md). Task/D-Day 별도 캐시 키의 갱신 경계를 별도 기능 단위로 점검한다. 제목·날짜·목표 변경 후 이전/새 목표 목록의 반영을 확인한다. 실제 서버 재현과 원인 확정은 미완료다.

- 새 Goal의 상세 연결/해제와 오늘 회차 연결은 현재 API로 진행할 수 있다. G-07을 이유로 전부 멈추지 않는다.
- Goal 아래 모든 일회성 Task/일정의 정확한 전체 목록은 G-07(미전달·미합의)의 별도 지원 확인이 필요하다. 현재 일부 날짜 결과나 mock 가짜 항목을 전체 목록으로 표시하지 않는다.
- 목표 안 혼합 순서의 기기 간 저장은 G-06 후속이다. 새 Plan의 순서 지원과 기존 D-Day의 로컬 순서를 구분한다.
- UI에서 만든 필드를 임의로 서버에 보내지 않는다. API 변경이 필요하면 기존 변경 요청서에 요구와 예상 계약을 먼저 추가한다.

## 다음 구현의 검토 조건

이번 전체 감사는 수정 목록까지 작성했다. 다음 코드는 위 순서의 작은 완결 단위로 진행한다. 새 화면·선택기·달력 모드처럼 의미 있는 대안이 있으면 3개 시각안을 비교한 뒤 선택한다. 현재 선택 시안의 국소 수정은 기존 안을 보정한다. 변경 후 정상·빈 상태·실패·복구의 실제 캡처와 `npm run validate` 결과, Android/iOS/Web 영향 및 미검증 항목을 기록한다.

실기기 글자 확대·키보드·safe area·VoiceOver/TalkBack·dark·실제 인증/네트워크 오류는 별도 검증 항목이다. 이번 Web 감사나 자동 검사 통과로 이를 완료 처리하지 않는다.
