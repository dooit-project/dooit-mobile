# 반복 가능한 일상 행동 — 백엔드 보충 확인서

작성: 2026-10-13 · 상태 갱신: 2026-10-18 · 목표 중심 변경 요청서에서 참조해 전달됨, 복수 계획/시간 없는 회차/실천 계약 회신 수신

현재 상태는 [백엔드 회신 대조 기록](../integration/BACKEND_HANDOFF_2026-10-18.md)을 따른다. Goal Plan·선택 요일·기본/최소 행동·다음 행동과 회차 결과 계약을 로컬 문서/controller에서 확인했고 운영 목표 API 배포 보고를 수신했다. 전체 보충 시나리오의 모바일 연결·개별 제품 정책 합의·실기기 검증이 끝난 것은 아니다. 아래 질문은 최초 전달 이력으로 보존한다.

기존 [시스템 요청서](./API_PERSONAL_SYSTEMS_REQUEST.md)의 범위를 대체하지 않는 보충입니다. 사용자의 핵심 사례는 매일 정해진 시각에 운동하기, 시각 없이 영단어 10개 같은 작은 행동을 반복하기입니다. 프로젝트의 다음 행동을 매회 바꾸는 경우만 대상으로 설계하지 않도록 확인 부탁드립니다.

전달 기준: [목표 중심 변경 요청서](./API_GOAL_JOURNEY_CHANGE_REQUEST.md)가 이 문서를 참조해 전달됐다. 단일 시스템 범위를 전제로 별도 중복 전달하지 않는다. 아래 시간 없는 행동·알림·nextAction 확인은 여러 목표 연결 계획에도 적용한다.

## 확인할 계약

1. **시간 없는 매일 행동:** 일정 startAt 입력 없이 반복 날짜를 정할 수 있어야 합니다. 매일/평일/선택 요일, 기준일·시간대와 회차 날짜를 표현해 주세요. 기존 반복 Task로 재사용할 수 있는 범위와 별도 시스템 회차가 필요한 범위를 알려 주세요.
2. **주기·시작 단서·알림 분리:** 매일이라는 주기, 오전 7시 또는 식사 후라는 시작 단서, 알림 허용/시각을 독립적으로 다룰 수 있어야 합니다. 식사 후를 자동 감지하지 않습니다. 시간 없는 행동의 알림은 사용자가 선택했을 때만 지정합니다.
3. **기본/작은 행동:** 영단어 10개/1개, 1분/시간 없는 행동을 허용해 주세요. 초기에는 행동 설명과 STANDARD/MINIMUM 결과로 충분하며 범용 수량 카운터 신규 개발을 요청하지 않습니다. 계획 분량에서 실제 학습량·시간을 추정하지 않습니다.
4. **nextAction 선택:** 매일 같은 행동을 하는 시스템은 생성·실천에서 다음 행동을 생략할 수 있어야 합니다. 기존 값 유지·명시적 비우기 정책은 원 요청서와 같습니다. 첫 실천부터 필수 입력으로 강제하지 말아 주세요.
5. **실천과 쉬기:** 명시적 기본 행동 확인·최소 행동 확인·휴식·취소를 지원하고, 과거 미실행을 다음 날 분량이나 밀린 Task로 누적하지 않습니다. 이 원칙은 기존 BE-02/03을 재확인하는 것입니다.

## 기존 기능 재사용 확인

모바일 일반 작성은 현재 SCHEDULE에만 반복/알림을 제출합니다. 이 프론트 제약을 서버의 TODO 반복 불가 정책으로 단정하지는 않습니다. 기존 API가 시각 없는 반복 TODO를 이미 지원하는지, 어떤 입력·응답인지 확인 부탁드립니다.

모바일 템플릿 UI에는 다중 요일 입력이 있지만 로컬 mock의 템플릿 적용 분기는 반복 필드를 생성 Task에 반영하지 않습니다. 실제 템플릿 적용 API에서 반복 묶음/회차가 생성되는지 예시 응답을 부탁드립니다. mock 결함은 프론트에서 별도 수정할 항목이며 서버도 같은 결함이 있다고 가정하지 않습니다.

자연어 quick capture의 `매일 오전 7시 운동`, `매일 영단어 10개`, `평일 영단어 10개`, `월·수·금 운동` 지원 범위와 해석 응답을 알려 주세요. 지원되지 않으면 프론트는 명시적 주기 입력을 제공합니다. 기존 quick capture 유형 불일치 문제와 함께 확인할 수 있습니다.

## 서버 변경이 필요 없는 부분

동기부여 문구의 교체·노출 간격·최근 문구 중복 방지·덜 보기/숨기기는 첫 버전에서 앱 내 검토된 문구와 계정별 로컬 설정으로 구현합니다. 별도 명언 API·CMS·push·AI 명언 생성은 요청하지 않습니다.

원 요청서의 시스템·회차·실천·주간 증거·AI 계약에 위 사례가 포함되는지와 추가 제약만 회신해 주세요. 아직 합의되지 않은 경로·필드를 운영 기능으로 간주하지 않습니다.
