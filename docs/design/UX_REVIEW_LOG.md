# UX Review

Last updated: 2026-10-23

현재 제품 결정과 남은 위험의 요약이다. 최신 근거는 [10월 22일 실제 Web 재감사](../audits/visual-cohesion-2026-10-22/README.md)와 [완성도 개선 기준](./VISUAL_COHESION_REVIEW_2026-10-22.md)이다. 앞선 [전체 UI/UX 감사](../audits/whole-app-2026-10-21/README.md)의 기능 과제와 [후속 작업](../product/UI_UX_BACKLOG_2026-10-21.md)도 유지한다. 구현 순서는 [로드맵](../product/ROADMAP.md) 최신 절을 따른다. 이전 문서의 Today 주간 strip·더보기 탭·완료 최근 3개 노출을 현재 구현으로 보지 않는다.

새 실제 캡처 23장에서 헤더/본문의 최대 폭 불일치, 새 목표 탭의 화면 밖 선택, 반복 폼 오류 후 초점 미복귀, 달력 공간 배분을 확인했다. 공통 헤더·시각 규칙을 먼저 정리하며 아래 수치는 현재 코드 기준이다. 새 제안 수치를 구현된 토큰으로 간주하지 않는다.

후속 첫 개발 단위로 [헤더·Today 간격](../audits/header-alignment-2026-10-22/README.md)을 반영했다. 헤더 최소 56, 메뉴 그림 24/터치 44, 공통 wordmark 26/32, 최대 폭 720, Today 위 간격 16이다. 긴 명언 두 개는 설정에 원문을 유지하고 헤더 순환에서 제외했다. 아래 과거 수치 중 ‘헤더 52’는 이 보정으로 대체한다. 같은 큰 틀을 유지하는 작업 규칙은 [구현 가이드](./DESIGN_IMPLEMENTATION_GUIDE.md)에 둔다.

목표 목록/상세와 헤더/가이드는 각각 `d714879`·`a3943d2`로 커밋했다. [공통 색 역할](../audits/neutral-text-2026-10-22/README.md)은 light `textSecondary` #4B5563, `textMuted` #667080으로 보정해 `20b9211`로 커밋했다. `AppText`와 기존 아이콘/탭/버튼의 역할을 공유하며 브랜드/선택/목표색·크기·구조는 유지한다.

이어서 [AppIcon 공통 규격](../audits/common-icons-2026-10-22/README.md)을 메뉴/목표/추가/날짜 이동/개인 상세와 탭에 적용해 `0702a28`로 커밋했다. 목록 24, 조작 22, 메타 14, 탭 28이며 그림을 접근성 이름에서 숨기고 부모 버튼의 이름/상태를 유지한다. native 플랫폼별 탭 그림 대신 공통 glyph를 사용한다. 실제 Web 전후/조작을 확인했고 native·글자 확대 결과와 제목/행/버튼 규격은 미완료다.

10월 23일 사용자 지적 후 [Drawer 균형 보정](../audits/drawer-icon-alignment-2026-10-23/README.md)을 반영해 `f1f07be`로 커밋했다. 한 줄 메뉴의 실제 획 중심은 일치해 전역 위치 이동 대신 메뉴만 20px/명시적 줄 높이로 바꾸고, 카테고리는 제목 줄 기준으로 맞췄다. 다른 화면의 조작 22·목록 24·탭 28은 유지한다. Web 펼침 상태 전달을 보완했고 390 전후·320·Escape 초점 복귀를 확인했다. native/확대는 미확인이다.

글자/행과 계획 아이콘 보정은 `1192c38`로 커밋했다. 다음 [공통 Button](../audits/button-hierarchy-2026-10-23/README.md)은 일반 라벨 16·compact 14, 저장/취소 위계와 테두리/로딩 공간을 보정했다(미커밋). 같은 390 목표 작성 전후, 320/430·키보드 초점·유효성·개인 편집 취소와 592 tests를 확인했다. 실제 로딩/native/모든 소비 화면은 미확인이다.

공통 버튼 보정은 `3cd3254`로 커밋했다. 이어서 [GoalTabs의 선택/노출](../audits/goal-tab-visibility-2026-10-23/README.md)을 반영했다(미커밋). 늦은 탭 측정과 좁은 표시 폭의 경계를 처리하고 aria-selected/본문 연결, Web 화살표 초점·Enter/Space 선택을 제공한다. 실제 320/390/430·생성/전체 목록/선택 복원과 597 tests 확인. native/확대/실제 서버는 미확인이다.

## 유지할 구조

계획의 첫 줄 기준이 위로 떠 보인다는 추가 지적 후 [아이콘 재보정](../audits/item-optical-alignment-2026-10-23/README.md)을 적용했다. 측정상 제목 중앙은 맞았지만 두 줄 전체 블록보다 11px 위였다. 계획 유형 그림은 제목+보조 전체 중앙, 오늘 체크는 기준 이미지의 첫 줄 중앙으로 역할을 구분한다. 앞선 계획 첫 줄 정렬 결정은 대체하며 미커밋이다.

2026-10-23 메뉴 균형 보정은 `f1f07be`로 커밋했다. 이어서 [오늘·계획의 글자/행](../audits/goal-item-typography-2026-10-23/README.md)을 sectionTitle 18/26·본문 16/24·보조 13/18로 공유하고 체크/유형 그림을 첫 줄에 맞췄다(미커밋). 390 실제 전후·320 긴 문구/계획·430 오늘·완료/취소를 확인했다. 버튼 위계/다른 화면의 글자 역할은 후속이며 Task 편집 후 D-Day 계획 목록의 제목이 갱신되지 않는 관찰은 UX-14로 분리했다. 이전 미커밋 표시는 당시 상태다.

- 하단은 오늘 / 달력 / 계획 / 돌아보기다. Drawer는 검색·기록함·다시 정리할 항목·보조 도구·계정/설정의 진입이다.
- 오늘은 그날의 실행이다. 큰 제목·상시 날짜·주 달력을 복원하지 않는다. 목표별 묶음과 간단한 체크를 기본으로 한다.
- 계획은 목표·선택 목표일·반복 정의·연결 항목의 생성/수정이다. 가로 목표 탭과 전체 목표 선택을 유지한다.
- 달력은 별도 하단 직접 진입으로 날짜별 항목을 찾는다. 현재 3주 그리드의 밀도와 주/월 이동 표시는 개선 대상이다.
- 돌아보기는 실제 행동의 기록이다. Goal 퍼센트·연속 달성 압박·기록 없는 성과/감정·AI 칭찬을 만들지 않는다.

## 공통 시각 기준

[첨부 원본 기준 정정](./goal-lanes-correction-2026-10-21/README.md)을 우선한다. 이전 ‘3번’ 카드형 연결은 참조 오류다. 일반 본문 16/24, label 14/20, 보조 13/18, 목표 제목 18/26, 기본 헤더 52·하단 탭 80에 플랫폼 inset을 더한다. 탭 아이콘 28, 선택은 밑줄이며 pill 배경은 없다. 역할별 위계를 조정하며 전체 글자를 같은 비율로 확대하지 않는다.

오늘은 흰 바탕·목표별 색상 레일·원형 마커로 구분하며 항목별 카드나 가로 줄은 없다. 완료 Task를 같은 목표 아래 남기고 체크/취소선/‘완료’로 상태를 알린다. 작은 문구는 로고 옆, 출처는 설정에서만 확인한다. 큰 명언 카드·자동 팝업·기록 평가로 만들지 않는다. [실제 비교·조작 감사](../audits/goal-lanes-correction-2026-10-21/README.md)의 확인 범위를 따른다.

## 현재의 주요 미완료

계획·상세의 흰 묶음, 빈 정보 축소, 날짜 버튼 배치와 실제 날짜 표시, 기록 펼침은 [첫 보정](./PLAN_DETAIL_SURFACES_2026-10-21.md)에 반영했다. 자동/실제 검증 범위는 해당 감사에 둔다. 아래의 새 Goal 회차·여정 흐름과 반복 폼 오류는 여전히 남아 있다.

- 매일 반복 계획이 있어도 오늘 회차 화면은 아직 연결하지 않았다. F3a-1 hook만 있다는 것을 실행 기능 완료로 표현하지 않는다.
- 개인 Task 상세는 아직 기존 D-Day 연결만 제공한다. 새 Goal과 D-Day의 ID를 구분해 연결하고 없는 ‘D-Day 탭’ 안내를 고친다.
- 오늘 빠른 작성은 기본 기록함 저장 후 오늘 이동이다. 오늘 문맥의 기본 목적지와 부분 성공 재시도 UX를 개선한다. 명시한 다른 날짜를 임의로 오늘로 바꾸지 않는다.
- 기존 Task 완료 후 항목 유지·취소는 반영했다. 새 Goal 회차/휴식/최소 행동·실제 Goal 여정은 후속이다.
- 상세의 빈 체크리스트는 작은 추가 진입으로, 빈 설명/‘없음’ 행은 생략하는 첫 보정을 반영했다. 항목이 있는 체크리스트·일정 정보와 기록 펼침은 실제 mock에서 확인했다.
- 반복 폼의 긴 필수 입력과 오류 필드가 화면 밖에 남는 문제를 해결한다. 이름/기본 행동의 중복 입력과 날짜/시간대 노출도 검토한다.
- 전체 목표 펼침의 본문 중복, 검색의 Task/D-Day 용어와 Goal 검색 범위, 선택적 첫 Goal 진입은 후속 목록을 따른다.
- mock 모듈 로드 날짜가 자정 뒤 일반 Task 완료에 사용되는 문제는 운영 서버 문제와 구분해 고친다.

## 접근성·검증 경계

- 터치 목표는 내부 44 이상이며 WCAG의 최소 기준과 구분한다. 측정한 달력 이전 주 버튼은 44×44다.
- 목표 tab의 Web aria-selected/tablist와 요일 버튼의 선택 상태가 빠져 있음을 DOM에서 확인했다. 시각 선택선만으로 완료 처리하지 않는다.
- Drawer Escape 닫기와 열기 버튼 초점 복귀는 실제 Web에서 확인했다. 전체 키보드·보조 기술 검증을 대신하지 않는다.
- 320px의 계획·회원가입과 390px 주요 흐름을 확인했다. native 글자 확대 1.5·키보드·safe area·dark·VoiceOver/TalkBack·대량 데이터·실제 네트워크 실패는 미검증이다.
- 공통 Button은 최소 높이를 사용하며 중요한 오류·결과 안내를 말줄임하지 않는다. light/dark 대비 자동 검사를 유지한다.
- 비활성 탭이 DOM snapshot에 남는 현상만으로 실제 보조 기술 노출을 단정하지 않는다.

## 인증·데이터·알림에서 유지할 조건

- 최초 사용은 `/start`의 게스트 시작/로그인 선택을 유지한다. 게스트 발급/토큰 확인 실패는 시작 단계에서 복구하며 Goal 입력을 강제하지 않는다.
- 게스트 데이터 보관 한계를 정확히 안내하고 실제 병합/동기화 완료를 과장하지 않는다. 계정 전환 뒤 이전 계정 캐시·문구·알림이 남지 않아야 한다.
- API/token 진단은 development build 전용이다. 실제 비밀 값은 화면 증거/문서에 남기지 않는다.
- 알림 권한을 최초 실행에서 강제하지 않고 거부 후 반복 요청하지 않는다. 실제 권한·전달·앱 종료/복귀는 native 검증 대상이다.
- Goal Plan 회차 알림과 연결 Task 알림을 중복 예약하지 않는다. 이번 UI 감사가 native 알림 연결 완료를 뜻하지 않는다.
- Workspace VIEWER에게 변경 행동을 제공한 뒤 403으로 막는 흐름을 기본으로 삼지 않는다. 이번 감사에서는 게스트 입구만 확인했다.

## 다음 리뷰

[후속 작업](../product/UI_UX_BACKLOG_2026-10-21.md)의 순서를 따른다. 각 변경 전에 기존 선택 시안과 사용자 목적을 확인하고, 의미 있는 새 화면/정보 구조는 세 가지 시각안을 비교한다. 구현 후 정상·빈 상태·실패·복구를 실제로 캡처하고 `npm run validate`, Android/iOS/Web 영향과 한계를 함께 기록한다.
