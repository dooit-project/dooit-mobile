# 오늘의 평소 행동과 작은 행동: 시각안

2026-11-08 시안 생성 · 2026-11-10 방향 합의 · 생성 시안, 실제 화면 아님

2026-11-10: 사용자가 [기능의 필요성·사용 가능성 재검토](./PRODUCT_REVIEW_2026-11-10.md)의 방향에 동의했다. 작은 행동을 선택 기능으로 두고 평소 체크를 간단히 유지하는 **1번 축소 방향**이다. 원본 1번의 버튼 크기와 문구를 그대로 채택한 것은 아니며, 구체적인 보정 시안과 기능은 아직 미완료다. [다음 작업 인수인계](../../product/HANDOFF_2026-11-10.md)를 따른다.

## 문제와 기준

[현재 mock Web 캡처](./current-390.png)에서 평소 행동을 ‘영단어 30개 외우기’, 작은 행동을 ‘영단어 3개 읽기’로 설정했는데 사용자가 선택하기 전에 작은 행동이 오늘의 제목으로 표시된다. 현재 연결 Task 체크는 UNKNOWN 결과이므로 보이는 분량을 실제 수행한 것으로 기록해서는 안 된다. 이 캡처는 테스트 게스트의 데이터다.

기존 [오늘 화면 선택 원본](../today-soft-groups-2026-11-06/refined-reference.png)의 작은 헤더·목표별 묶음·하단 탐색·체크 흐름을 유지한다. 평소 행동을 우선 안내하고 작은 행동도 쉽게 선택하게 하되, 선택과 완료를 혼동하거나 휴식을 실패로 표현하지 않는다. 다음 행동이 저장된 경우와 기존 UNKNOWN 결과도 별도로 다뤄야 한다.

## 생성 결과 표시 순서

1. [행의 작은 행동 전환](./01.png): 평소 행동 옆에서 작은 행동을 선택하고, 선택된 내용을 체크한다. 전환 시에는 저장 완료로 처리하지 않는다. 빠르게 발견할 수 있으나 반복 계획이 많거나 제목이 길 때 추가 조작이 목록을 복잡하게 만들 수 있다.
2. [완료 시 행동 선택 시트](./02.png): 체크 후 실제로 한 행동을 두 선택지 중 하나로 기록한다. 분량 확인이 명확하지만 매번 한 번 더 선택해야 한다. 그림에는 하단 탭이 중복 생성되어 있으며 이를 구현 기준으로 쓰지 않는다.
3. [행의 맥락 메뉴](./03.png): 평소 행동을 표시하고 항목의 메뉴에서 작은 행동으로 바꾼 다음 체크한다. 기본 목록은 간결하지만 작은 행동이 숨겨져 발견하기 어렵고 목표의 메뉴와 혼동할 수 있다.

그림의 이름·수량·날짜는 설명용 예시다. 텍스트·아이콘·메뉴의 실제 터치 영역과 작은 화면, 기록 전 선택 변경, 버전 충돌, 중복 제출, 결과 취소 및 오류 복구는 아직 검증하지 않았다. 어떤 안이든 사용자가 선택한 결과와 오늘·상세·돌아보기·목표 기록의 내용이 일치해야 하며, 기존 UNKNOWN 기록을 임의로 평소/작은 행동으로 바꾸지 않는다. 선택 결과가 없을 때 다음 행동과 서버가 만든 Task 제목을 어떻게 구분할지도 구현 전에 확인한다.

## 적용한 검토

Product Design `get-context`·`ideate`로 현재 실제 화면과 사용자 선택 시안을 직접 첨부하여 서로 다른 상호작용 세 가지를 생성했다. `imagegen-frontend-mobile`의 모바일 가독성·일관성 지침과 `better-layout`·`better-accessibility` 지침을 참고했다. 이는 디자인 탐색이며 실제 앱의 동작·접근성 검증이나 사용자 선호 조사 결과가 아니다. 이미 확인한 [Todoist 완료 항목 안내](https://www.todoist.com/help/todoist/features/view-completed-tasks-in-todoist-J19h2s)는 완료 상태를 목록과 기록에서 구분하는 참고 자료이며 이 세 안의 효과를 입증하지 않는다. 실제 외부 앱 조작은 하지 않았다.

사용자는 1번의 상호작용을 가볍게 보정하는 방향에 동의했다. 정확한 보정 화면은 아직 없고 앱 코드에도 반영하지 않았다. 화면에 표시된 순서와 위 번호가 일치한다.
