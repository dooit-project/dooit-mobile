# 달력 탐색 시각안

2026-10-30 · Product Design ideate · [기존 실제 감사](../../audits/calendar-review-2026-10-30/README.md)

목적: 주 이동과 월 제목의 관계, 달력의 빈 공간, 선택한 날짜의 목록 문맥을 검토한다. 기준은 현재 실제 달력과 [사용자 선택 오늘 시안](../goal-lanes-correction-2026-10-21/reference.png)이다. 흰 바탕·공통 헤더·오늘/달력/계획/돌아보기 탭과 기존 목표·할 일 관계를 유지한다. 그림은 동작하는 앱이나 확정 명세가 아니다.

이미지는 대화에 표시된 순서로 연결한다.

1. [첫 번째](./01.png): 한 주와 목표별 항목 중심. 생성 그림의 두 번째 목표 이름과 항목은 중복되어 데이터 계층의 명세로 사용하지 않는다. 원래 세 주를 요청했지만 실제 생성 결과는 한 주다.
2. [두 번째](./02.png): 월 전체 그리드와 선택 날짜 목록 중심. 달력 이동 단위와 일정 표시 밀도를 살펴볼 수 있다.
3. [세 번째](./03.png): 한 주와 시간순 날짜 목록 중심. 월 선택과 주 이동 화살표의 관계를 구현 전에 명확히 정해야 한다.

날짜·시간·요일은 예시이며 실제 데이터나 이용 기록이 아니다. 점·선·배지·글자 크기·구체적인 목표 분류를 무조건 구현하는 승인으로 해석하지 않는다. 세 안 모두 월 밖 기간 일정, 반복, 빈 날짜, 많은 일정, 긴 제목, 320px과 접근성의 실제 동작은 보여주지 못한다. 사용자 선택 전에는 앱 구조를 변경하지 않는다.

사용자는 2번을 선택했고 월간 달력의 높이·다른 서비스 패턴을 검토하며 진행하도록 요청했다. 이를 바탕으로 [04 보정 원본](./04-refined.png)을 생성하고 기존 선택 원본 2번과 함께 기준으로 사용했다. 기존 화면과 다른 체크/카드 형태까지 자동으로 확정하지 않는다. [구현 및 실제 범위](../../audits/calendar-month-2026-10-30/README.md)를 확인한다.
