# 메뉴 진입과 탐색 문구 정리

2026-10-17 · 코드 반영 · 미커밋·미검증

## 목적과 기존 결정

오늘은 실행, 달력은 날짜 탐색, 계획은 목표 구성, 돌아보기는 목표별 주간 완료 기록을 담당한다. 핵심 네 탭과 왼쪽 메뉴를 유지하며 보조 기능과 계정 관리의 진입을 연결한다.

확인 대상은 `PlannerDrawer`, 탭 layout, 숨김 처리된 `/profile`, 계정·설정·검색·공유 공간·완료 기록·템플릿·오늘 보조 화면의 코드다. 기존 [메뉴 캡처](../audits/navigation-drawer-2026-08-31/implementation-open-final.png)를 직접 열어 행·아이콘·그룹 배치를 참고했다. 이 이미지는 과거 구현 참고이며 현재 앱의 감사 증거가 아니다.

구현 전 기존 코드와 [메뉴를 유지하고 계정·설정을 메뉴에서 접근시키는 결정](./to-be-2026-10-14/UI_REFINEMENTS.md)을 확인했다. 해당 문서의 날짜/달력 위치는 후속 결정으로 대체됐으며 메뉴 유지 원칙만 재사용한다. 새 내비게이션 구조를 선택하는 단계가 아니라 기존 행 패턴으로 누락된 진입과 표시 오류를 복구하므로 새 시각안 세 개를 만들지 않는다.

## 이번 변경

- **계정 진입 복구:** `/profile`은 탭에서 숨겨졌지만 기존 로그인·로그아웃·게스트 안내는 그 화면에 있다. 메뉴의 설정 앞에 `계정`을 추가해 기존 화면으로 연결한다. 계정 처리와 데이터 전환 로직을 새로 만들지 않는다.
- **선택 표시 수정:** `기록함`, `오래 미룬 일`의 실제 목적지는 `/today/review`의 서로 다른 `focus`다. 없는 `/inbox`, `/overdue` 경로 대신 실제 경로와 focus 값을 함께 비교하도록 수정한다. 기록함/오래 미룬 일 이동 자체는 기존 경로를 유지한다.
- **뒤로가기 안내:** 메뉴나 상세 등 여러 위치에서 진입할 수 있으므로 접근성 이름을 `더보기 화면으로 돌아가기`에서 `이전 화면으로 돌아가기`로 고친다. 실제 동작은 기존 history back이다. 직접 URL 진입 시 history가 없는 경우의 대체 경로는 이번에 추가하지 않았다.
- **완료 기록 구분:** 메뉴·계정 도구 목록·기존 완료 화면은 `날짜별 완료 기록`으로 맞춘다. 새 돌아보기 탭은 목표별 주간 기록을 보여주며, 기존 화면의 날짜별 확인/완료 취소 경로도 유지한다.
- **용어 일치:** 메뉴·계정 도구 목록·템플릿 화면의 제목과 접근성 이름에서 `Task 템플릿`을 `할 일 템플릿`으로 맞춘다. 오늘 보조 화면/완료 화면의 복귀 문구는 `오늘로 돌아가기`로 통일한다. 내부 API·타입 이름은 바꾸지 않는다.

새 화면·API·의존성은 없다. 기존 메뉴의 검색·카테고리·공유 공간·기록함·목표·완료 기록·설정 경로는 유지한다. 계정 화면의 도구 목록과 메뉴의 중복을 한꺼번에 삭제하지 않는다. 대체 경로 검증을 보류한 상태이므로 이번 변경을 중복 탐색 정리 전체의 완료로 간주하지 않는다.

## Product Design 검토 범위

- 적용 기준: Product Design index/audit 지침과 저장소의 [기본 검토 정책](../qa/PRODUCT_DESIGN_REVIEW_POLICY.md)을 읽고 실제 감사와 코드 검토를 구분했다. 사용자 요청에 따라 새 캡처 기반 감사는 수행하지 않았다.
- 참고 자료: [기존 구조 검토](../product/PRODUCT_ARCHITECTURE_REVIEW_2026-10-13.md)에 기록된 Todoist 탐색 안내/모바일 탐색 연구를 재사용한다. 핵심은 하단에 노출하고 보조 목적지는 메뉴에 유지한다는 기존 판단이다. 이번에 외부 앱·Figma를 새로 조작하거나 최신 사양을 확인하지 않았다.
- 행동 위계: 주요 네 탭은 유지하고 계정은 설정 옆의 기존 보조 메뉴 그룹에 둔다. 로그인/로그아웃 버튼을 핵심 실행 화면에 추가하지 않는다.
- 시각·접근성 조건: 기존 60dp 메뉴 행·아이콘·선택 상태·스크롤을 재사용한다. 길어진 완료 기록 이름과 추가된 계정 행의 작은 화면/글자 확대/키보드 초점/화면 읽기 순서는 실제 확인이 남아 있다.
- 검증: 사용자 요청에 따라 `npm run validate`, 테스트, 구현 후 실제 화면 감사는 보류했다. 코드 반영과 포맷 정리를 검증 통과로 표현하지 않는다.
- 영향 플랫폼: Android·iOS·Web 공통 클라이언트.

## 다음 작업

메뉴 헤더 크기·그룹 밀도, 계정 화면의 도구 목록 중복, 목표/완료 기록의 중복 진입은 별도 탐색 정리 범위다. 구조를 바꾸려면 기존 링크의 대체 경로를 정하고 의미 있는 시각 선택지를 먼저 비교한다. 직접 URL 진입의 안전한 복귀도 후속 대상이다.
