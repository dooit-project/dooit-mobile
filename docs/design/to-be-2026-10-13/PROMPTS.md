# TO-BE 이미지 생성 프롬프트

2026-10-13 · built-in ImageGen 사용 · 표시 순서대로 독립 호출 3회

참조: 최신 Today·달력 실제 캡처와 사용자가 선택한 기존 3번 실행 sheet. 이미지 첨부 경로와 프롬프트의 viewport는 논리 규격이다. 출력은 1672×941 보드이며 개별 모바일 화면은 해당 보드에 축소 표시됐다.
