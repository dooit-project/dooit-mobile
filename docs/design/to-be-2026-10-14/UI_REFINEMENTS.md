# 목표 중심 UI 세부 보완

2026-10-14 · 사용자 피드백 반영 · 구현 전

[전체 앱 수정 시안](./GOAL_GROUPED_REVISION.md)의 목표별 체크 목록·일정·완료 기록 방향은 사용자가 긍정적으로 평가했다. 큰 Today 제목, 모호한 달력 버튼, 예시 문구는 수정한다. 이전 이미지의 메뉴 누락은 제거 승인으로 해석하지 않는다.

## 상단과 탐색

- 공통 상단: 메뉴 버튼 → dooit → 짧은 순환 문구. 중복 프로필 버튼은 없애고 계정·설정은 메뉴에서 접근한다.
- Today 제목은 20px 전후, 날짜는 14px로 한 줄에 배치한다. 큰 제목과 별도 날짜 블록이 차지하던 높이를 줄인다.
- 달력 진입은 날짜 행 오른쪽의 달력 아이콘 + `달력 보기` 테두리 버튼으로 표현한다. 터치 영역은 최소 44×44dp, 버튼 전체가 하나의 접근성 대상이다.
- 좁은 화면·큰 글꼴에서는 날짜 행을 자연스럽게 두 줄로 배치한다. 문구 때문에 메뉴·달력 버튼이 밀리지 않게 한다. 문구는 자동 가로 스크롤하지 않는다.
- 하단은 오늘·계획·돌아보기. 달력은 눈에 보이는 별도 버튼으로 한 번에 접근한다.
- 현재 PlannerDrawer의 검색·공유 공간·기록함·오래 미룬 일·템플릿·설정 경로를 유지한다. 목표와 완료 기록 등 중복 링크 정리는 대체 경로 검증 이후 진행한다.
- 일정 추가와 Task 완료는 기존 목표 아래의 맥락을 유지한다. 목표 달성률은 표시하지 않는다.

[NN/G 메뉴 연구](https://www.nngroup.com/articles/hamburger-menus/)는 숨겨진 탐색의 발견 가능성 비용을 보여준다. 이를 적용한 판단은 핵심 목적지는 하단에 계속 노출하고, 보조 목적지는 기존 메뉴로 접근시키는 것이다. 메뉴 자체를 없애야 한다는 의미로 해석하지 않는다.

## 출처를 확인한 문구 후보

아래 한국어는 공식 한국어판 인용이 아닌 직접 번역·의역 후보다. 원문과 저자·출처·번역 구분을 함께 관리한다. 짧게 다시 쓴 제품 문구를 저자의 정확한 인용처럼 표시하지 않는다.

상단에는 짧은 문장만 표시하고, 누르면 저자·원문·번역 구분·출처·다른 문장·숨기기를 확인할 수 있게 한다. 긴 문장은 상세에서 읽고 상단에는 짧은 후보를 우선한다. 새 날에 교체하며 최근 문장 중복을 피한다. 화면을 보는 동안 자동으로 교체하지 않는다. 휴식·복귀 상황에 노력이나 죄책감을 강요하는 문장은 제외한다.

## 다음 시각 검토 기준

목표 그룹과 체크 목록은 유지하고 상단 높이·메뉴 복원·달력 버튼만 수정한 단일 시안을 만든다. 이번 문서는 실제 UI 구현이나 화면 감사 결과가 아니다.
