# Today 목표 그룹 표현 비교

2026-10-14 · Product Design 시각 비교 · 구현 전

사용자가 옅은 가로 구분선도 어색하다고 평가해, 같은 정보 구조를 유지하면서 선 없이 목표와 하위 항목의 관계를 표현한 세 안이다. 이미지 표시 순서와 번호가 선택 기준이다.
