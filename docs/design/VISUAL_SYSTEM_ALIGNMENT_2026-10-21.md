# 선택 시안에 맞춘 공통 UI 보정

2026-10-21 · 사용자 승인으로 커밋 진행 · Android/iOS/Web 공통

자동 검증: `npm run validate` 통과(112 suites / 584 tests, STG integration 1개 제외). Web의 실제 캡처와 시각 판단은 아래 감사 범위를 따르며 자동 검사 통과와 구분한다.

사용자 요청: 계획 화면을 기존 선택 시안에 최대한 맞추고 공통 요소의 크기·색도 시안 기준으로 정리한다. 명언은 헤더에서 저자 표시 없이 문장만 보여주며 영문을 포함한다. [선택 시안](./plan-navigation-2026-10-15/05-goal-tabs-polished.png)을 유지하는 보정으로 새 정보 구조나 세 가지 디자인을 다시 제안하지 않았다.

## 공통 기준

| 역할           | 구현                                                              |
| -------------- | ----------------------------------------------------------------- |
| 브랜드/선택    | 로고 `#0875F9`, 동작/선택 `#1769E0`, 보조 정보 `#425E82` (light)  |
| 본문           | 16 / 줄높이 24                                                    |
| label / 보조   | 14/20, 13/18                                                      |
| 헤더           | safe area 외 기본 최소 높이 52, 로고 28/36, 문장 13/18 최대 두 줄 |
| 하단 탭        | 기본 높이 80 + bottom inset, label 14/20, 아이콘 28               |
| 화면 좌우 여백 | compact 16, 그 외 20                                              |
| 계획 목록      | 아이콘 26, 행 최소 높이 72, 아이콘-본문 간격 20                   |
| 계획 제목      | 24/32, 목표일 본문 16/24                                          |

모든 글자를 같은 비율로 확대하지 않았다. 공통 AppText·Button label·theme와 탭을 수정해 다른 페이지에도 같은 역할의 크기와 색이 적용된다. 파란 primary는 버튼 흰 글자 대비를 위해 로고보다 어둡게 사용한다. dark의 기존 대비 체계는 유지하고 브랜드 밝기만 별도로 제공한다.

하단 Web의 수제 도형 아이콘을 제거하고 Android/Web은 Feather의 sun/calendar/list/clock으로 통일했다. iOS는 동일 의미의 SF Symbols를 regular/monochrome으로 사용한다. 기존 설치 패키지를 사용하므로 의존성은 추가하지 않았다. 헤더 메뉴·계획 목록·추가 행도 선형 아이콘을 사용한다. 기존 항목 순서 편집 등 보조 흐름의 모든 아이콘까지 이번에 교체하지는 않았다.

## 계획과 저장 경계

목표 탭은 활성 파란 선택선·목표색 점·원문 제목을 유지한다. 전체 목표는 grid 아이콘과 고정 진입점으로 둔다. 관리 메뉴는 IconButton의 새 plain variant를 사용해 평소 배경을 없애고 포커스·눌림·펼침 상태는 남긴다. AddItemRow를 공통 컴포넌트로 추가해 새 반복 계획과 기존 D-Day 항목 추가를 왼쪽 정렬한다. 모든 IconButton을 강제로 투명하게 바꾸지는 않는다.

블루 목표색을 더 선명하게 조정했다. 이전 `#738DA3` 저장값은 읽을 때 블루로 대응하고 목표/선택/순서/다른 색을 보존한다. 읽기만으로 저장소를 덮어쓰지 않으며 Goal과 D-Day의 독립 namespace를 유지한다. 서버 색상 계약은 변경하지 않았다.

새 Goal의 단일 항목 추가·일회성/일정 목록은 G-07 계약 후속이다. ‘반복 계획 추가’ 라벨은 지원 범위를 정확히 나타내기 위해 남긴다. 시안처럼 보이게 하려고 미구현 항목을 실제 데이터에 섞지 않았다.
